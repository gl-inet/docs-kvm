# Por qué no se conservan los ajustes del altavoz y del micrófono {#why-cant-i-keep-my-speaker-and-microphone-settings}

Si activa Speaker o Microphone en la consola KVM desde Settings -> Remote Device Settings, puede observar que estos ajustes no se conservan al reiniciar, volver a iniciar sesión o actualizar la página durante el acceso local.

Speaker se desactiva automáticamente. Microphone, aunque siga apareciendo activado después de reiniciar o actualizar la página, queda silenciado.

![Ajustes del altavoz y del micrófono](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/speaker_microphone_settings.png){class="glboxshadow"}

Esto ocurre porque las políticas de seguridad del navegador desactivan o silencian Speaker y Microphone de forma predeterminada cada vez que reinicia, vuelve a iniciar sesión o actualiza la página durante el acceso local. Puede activarlos manualmente si los necesita.

La primera vez que active Microphone deberá autorizarlo, como se muestra a continuación.

![Permiso del navegador para el micrófono](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/google-browser.jpg){class="glboxshadow"}
