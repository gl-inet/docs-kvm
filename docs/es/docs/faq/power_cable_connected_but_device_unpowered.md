# Qué hacer si el KVM no se enciende {#what-should-i-do-if-my-kvm-does-not-power-on}

Si el KVM no arranca con el cable de alimentación conectado, siga estos pasos para identificar el problema.

1. Asegúrese de que el cable de alimentación esté conectado al puerto USB Type-C correcto.

    Por ejemplo, Comet (GL-RM1) tiene dos puertos USB Type-C: uno de entrada de alimentación, conectado al adaptador de corriente, y otro de transmisión de señales, conectado al dispositivo controlado mediante un cable USB.

    Si intercambia los puertos, el KVM no se encenderá y el ratón y el teclado no responderán.

    Conecte el cable de alimentación al puerto USB Type-C situado junto al puerto Ethernet.

    ![Conectar el cable de alimentación](https://static.gl-inet.com/docs/kvm/faq/power_cable_connected_but_device_unpowered/plug_in_power_cable.jpg){class="glboxshadow"}

2. Pruebe un adaptador de corriente convencional de 5V 2A y compruebe si se enciende el LED.

    Evite utilizar adaptadores de corriente con protocolo PD.

    Un LED azul fijo indica que el dispositivo está arrancando.

3. Mantenga pulsado el botón Reset durante más de 8 segundos para restablecer los ajustes de fábrica.
