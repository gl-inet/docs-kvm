# Qué hacer si la aplicación GLKVM no encuentra ningún dispositivo {#what-should-i-do-if-no-device-is-found-in-the-glkvm-app}

Al añadir un KVM por primera vez mediante **Auto Discover**, la aplicación GLKVM puede mostrar **No device found**.

![No se encontró ningún dispositivo](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

Pruebe lo siguiente:

1. Asegúrese de que todos los cables estén conectados correctamente al KVM: el cable Type-C de alimentación, el HDMI, el Ethernet si es necesario y el USB-A.

2. Asegúrese de que el KVM esté conectado a Internet. Un LED blanco fijo indica que la conexión de red funciona normalmente.

3. Compruebe que el KVM y el dispositivo de control estén conectados a la misma red.
