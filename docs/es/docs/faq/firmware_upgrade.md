# Cómo actualizar el firmware del KVM {#how-to-upgrade-your-kvms-firmware}

Las actualizaciones de firmware añaden funciones y mejoran la estabilidad del dispositivo. Siga estos pasos para realizar la actualización.

1. Inicie sesión en la consola KVM y haga clic en la versión de firmware, en la esquina superior derecha, para buscar actualizaciones.

    ![Actualización de firmware](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. Si hay un firmware más reciente disponible, la ventana emergente le permitirá realizar una **actualización en línea**. De lo contrario, el firmware de su KVM ya está actualizado.

    ![Firmware actualizado](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. Haga clic en **Update Settings** para realizar una actualización local, unirse al programa beta o guardar la configuración actual.

    ![Ajustes de actualización](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade**: descargue el firmware más reciente del [centro de descargas de firmware](https://dl.gl-inet.com/kvm){target="_blank"} antes de realizar una actualización local.

    - **Join Beta Program**: el firmware beta le permite probar próximas funciones de forma anticipada. Las versiones beta pueden ser inestables y afectar al rendimiento del dispositivo. Únase únicamente si acepta probar software previo a su lanzamiento.

    - **Save current configuration**: conserva la vinculación con su cuenta del servicio de nube.
