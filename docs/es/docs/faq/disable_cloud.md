# Cómo desactivar el servicio de nube {#how-to-disable-cloud-service}

El servicio de nube del KVM GL.iNet está activado de forma predeterminada y permite vincular dispositivos KVM a su cuenta de la nube para acceder a ellos de forma remota.

Si no desea utilizarlo, puede desactivarlo manualmente. Al hacerlo, el acceso remoto desde el servicio de nube y la aplicación GLKVM dejará de estar disponible. Para volver a activarlo, deberá iniciar sesión en el KVM de forma local mediante su dominio o dirección IP, o de forma remota mediante Tailscale.

Siga estos pasos si necesita desactivar el servicio.

1. Inicie sesión en el KVM y vaya a **Cloud Service**, en la esquina superior derecha. Haga clic en el icono de engranaje y después en **Disable**.

    ![Desactivar el servicio de nube](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_1.png){class="glboxshadow" width="400"}

2. Una vez desactivado, la página tendrá el siguiente aspecto.

    ![Servicio de nube desactivado](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_2.png){class="glboxshadow"}
