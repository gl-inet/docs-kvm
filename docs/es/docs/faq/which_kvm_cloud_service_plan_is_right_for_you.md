# Qué plan del servicio KVM Cloud le conviene {#which-kvm-cloud-service-plan-is-right-for-you}

El servicio KVM Cloud ofrece dos planes: Standard, gratuito, y Advanced, de pago. Screen Wall y Device Sharing son funciones exclusivas de Advanced. La tabla siguiente compara las funciones de ambos planes. Puede actualizar a Advanced cuando lo necesite.

## Comparación de prestaciones {#benefits-comparison}

| Función principal | Standard | Advanced |
| ---- | ---- | ---- |
| Conexión básica | ✓ Conexión básica de por vida | ✓ Conexión básica de por vida |
| Dispositivos vinculados | ✓ Dispositivos ilimitados en la cuenta | ✓ Dispositivos ilimitados en la cuenta |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">No disponible</span> | ✓ Hasta **9** incorporaciones |
| Device Sharing | <span style="color:red;">✗</span> <span style="color:#888;">No disponible</span> | ✓ Compartir con hasta **5** usuarios |
| Vías de acceso remoto | ✓ Una vía activa por dispositivo | ✓ Varias vías simultáneas por dispositivo |
| Acceso a dispositivos conectados | ✓ Dispositivos ilimitados | ✓ Dispositivos ilimitados |

**Nota**: las vías de acceso remoto se aplican a la nube y a las aplicaciones GLKVM.
