# Aplicación GLKVM {#glkvm-app}

![Icono de la aplicación GLKVM](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

GLKVM es una aplicación para Windows y macOS que permite acceder y controlar de forma remota los dispositivos conectados al KVM GL.iNet. Resulta útil para profesionales de TI, personas que trabajan a distancia y usuarios avanzados que necesitan acceso directo a equipos remotos.

Si utiliza macOS, descárguela desde [aquí](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"}.

Si utiliza Windows, descárguela desde [aquí](https://www.gl-inet.com/app-rm/){target="_blank"}; solo es compatible con Windows 10 y versiones posteriores.

Si utiliza Android, descárguela desde [aquí](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"}.

Si utiliza iOS, descárguela desde [App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"}.

También puede utilizar el servicio de nube para acceder de forma remota mediante un navegador. Consulte los detalles [aquí](remote_access_via_cloud.md).
