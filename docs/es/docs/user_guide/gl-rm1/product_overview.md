## LED {#led}

Comet tiene un indicador LED en el panel superior.

| Estado del LED | Descripción |
| :----------------------- | :-------------------------------- |
| Azul fijo | Iniciando |
| Blanco intermitente | Iniciado, sin conexión a Internet |
| Blanco fijo | Conectado a Internet |
| Azul y blanco intermitentes | Actualizando el firmware |

## Botón {#button}

Comet tiene un botón en el panel lateral.

| Función | Operación | Estado del LED |
| :------------------------- | :--------------------------------------- | :------------------------------------ |
| Entrar en el modo de flasheo U-Boot | Con el dispositivo encendido, mantenga pulsado <br>el botón durante más de **3s** y suéltelo | Al pulsar el botón: azul intermitente <br>En el modo U-Boot: azul fijo |
| Restablecer | Con el dispositivo encendido, mantenga pulsado <br>el botón durante **8–20s** y suéltelo | Pulsación de 1-8s: parpadeo lento <br>Pulsación de 8-20s: parpadeo rápido |

## Contenido del paquete {#package-contents}

- 1 x Tarjeta de agradecimiento
- 1 x Cable Ethernet
- 1 x Cable HD
- 1 x Cable USB (Type-A a Type-C)
