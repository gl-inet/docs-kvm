# Guía de usuario de Comet (GL-RM1) V1/V2 {#comet-gl-rm1-v1v2-user-guide}

Comet (GL-RM1) V1/V2 es un dispositivo KVM remoto con múltiples aplicaciones. Puede utilizarlo para controlar el ordenador de su casa cuando esté fuera o acceder a recursos locales, entre otras tareas. Permite controlar de forma remota dispositivos sin conexión, resolver fallos de arranque y ajustar la BIOS. También ofrece transferencia remota de archivos para intercambiar datos fácilmente con ordenadores con o sin conexión. Su compatibilidad con audio mejora la experiencia de interacción remota. Es una herramienta esencial para el trabajo remoto y la gestión de dispositivos.
