## Características destacadas {#highlights}

1. **5G RedCap**

    Comet 5G integra la avanzada tecnología 5G RedCap para proporcionar un acceso flexible a Internet, sin que sus instalaciones dependan de las redes fijas del lugar.

2. **Conmutación por error de red**

    Gracias a su conectividad móvil integrada y a la compatibilidad con Wi-Fi 6 y la conmutación por error de Ethernet, Comet 5G mantiene la disponibilidad continua: si falla una conexión, cambia automáticamente a la siguiente red disponible, lo que permite utilizar el KVM remoto sin interrupciones incluso en condiciones difíciles.

3. **Wi-Fi 6 de doble banda**

    Comet 5G admite Wi-Fi 6 de doble banda (2.4GHz y 5GHz) para ofrecer una conectividad inalámbrica estable, de alta velocidad y baja latencia para el funcionamiento remoto y el acceso a datos.

4. **Control de proximidad mediante el modo AP**

    Comet 5G ofrece control de proximidad por Wi-Fi para una gestión local rápida sin conexiones por cable. Solo tiene que cambiar el modo de red Wi-Fi de Comet 5G al modo AP para generar un SSID Wi-Fi exclusivo. Conéctese a este SSID para acceder de forma segura a la consola de Comet 5G.

    **Nota**: Al activar el modo AP, Comet 5G se desconecta de su red Wi-Fi superior y solo permite el acceso de proximidad, sin conexión a Internet.

5. **Acceso remoto desde el navegador**

    Comet 5G permite acceder a su consola directamente desde un navegador web, sin instalar un cliente. Este acceso utiliza cifrado HTTPS seguro y evita las advertencias de certificados autofirmados, lo que facilita una conexión segura sin software adicional.

6. **Diseño cuidado y pantalla táctil**

    Comet 5G tiene una carcasa gris oscuro con contornos suaves, esquinas redondeadas y un acabado mate texturizado que combina durabilidad y calidad. La pantalla táctil TFT de 3.69 pulgadas ofrece una interfaz intuitiva para acceder rápidamente a las funciones del dispositivo y utilizarlo con fluidez.

7. **Pantalla 4K y audio bidireccional**

    Comet 5G admite una salida de vídeo de hasta 4K@30FPS con transmisión directa por HDMI OUT, lo que permite la visualización local y el acceso remoto simultáneos sin un divisor externo. También ofrece audio bidireccional para una comunicación clara en videoconferencias o asistencia técnica remota.

8. **Instalación en un servidor propio**

    Comet 5G permite una instalación flexible en un servidor propio con sistemas operativos habituales, como Linux y Ubuntu, para que tenga el control total del acceso remoto y la privacidad de los datos. El sistema requiere un servidor en la nube con una CPU de al menos dos núcleos y 2GB de memoria para ofrecer privacidad y un funcionamiento fiable.

9. **Control remoto de la alimentación**

    Comet 5G dispone de un puerto USB para conectar dispositivos externos, como una placa ATX o un Fingerbot, y controlar la alimentación de los equipos conectados de forma remota.

    **Nota**: Los accesorios opcionales se venden por separado.

## Bandas de frecuencia {#frequency-bands}

Comet 5G admite las siguientes bandas de frecuencia.

- **5G NR**

    3GPP Release 17 RedCap, funcionamiento SA (Sub-6 GHz) n1 / n2 / n3 / n5 / n7 / n8 / n12 / n13 / n14 / n18 / n20 / n25 / n26 / n28 / n30 / n38 / n40 / n41 / n48 / n66 / n70 / n77 / n78 / n79

- **LTE FDD**

    B1 / B2 / B3 / B4 / B5 / B7 / B8 / B12 / B13 / B14 / B17 / B18 / B19 / B20 / B25 / B26 / B28 / B30 / B66 / B70

- **LTE TDD**

    B34 / B38 / B39 / B40 / B41 / B42 / B43 / B48
