# Guía de usuario de Comet 5G (GL-RM10RC) {#comet-5g-gl-rm10rc-user-guide}

Comet 5G (GL-RM10RC) es un KVM remoto compatible con 5G RedCap que integra conectividad móvil para proporcionar un control completo del dispositivo, incluso en zonas sin acceso a una red cableada, lo que aumenta considerablemente la flexibilidad de instalación. Admite conmutación por error entre 5G RedCap, Wi-Fi 6 y Ethernet para mantener la conectividad en distintas condiciones de red.

Su pantalla táctil integrada simplifica la configuración y las operaciones cotidianas, con una interfaz sencilla y eficiente para la gestión remota. Al utilizarlo con accesorios como una placa ATX o un Fingerbot, permite encender y apagar los equipos conectados de forma remota, por lo que resulta adecuado para la gestión distribuida y el mantenimiento sobre el terreno.
