# Guía de usuario de Comet Q (GL-RMQ1) {#comet-q-gl-rmq1-user-guide}

Comet Q es un dispositivo del tamaño de la palma de la mano que puede conectarse a teléfonos móviles, Mac mini o portátiles mediante USB-C. Una vez conectado, basta con abrir un navegador para controlar por completo el dispositivo de destino, sin instalar software adicional ni realizar configuraciones complejas. Su pantalla táctil integrada de 1.8 pulgadas permite configurarlo rápidamente, consultar su estado y ejecutar acciones directamente desde la unidad.

Es el primer KVM del mundo compatible con iPhones y permite desbloquear, tocar, deslizar el dedo y manejar por completo un dispositivo iOS desde un PC con Windows, una función que antes no estaba disponible.
