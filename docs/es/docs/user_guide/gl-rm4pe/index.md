# Guía de usuario de Comet X (GL-RM4PE) {#comet-x-gl-rm4pe-user-guide}

Comet X es un KVM remoto de cuatro puertos compatible con PoE que se conecta a un máximo de 4 servidores del rack. Una vez configurado, puede controlar todos los dispositivos conectados desde cualquier lugar mediante un navegador o una aplicación, con vídeo fluido 4K@30fps y sin software adicional. Su pantalla táctil integrada de 3.69 pulgadas permite consultar de un vistazo las direcciones IP, el estado de conexión y las sesiones activas. La alimentación PoE simplifica la instalación y reduce el cableado del entorno de servidores. Los 64GB de almacenamiento eMMC también sirven como repositorio integrado de archivos ISO para facilitar la instalación de sistemas operativos y la recuperación de emergencia.
