# Guía de usuario de Comet Pro (GL-RM10) {#comet-pro-gl-rm10-user-guide}

Comet Pro (GL-RM10) es una solución KVM remota a través de Wi-Fi. Incluye una CPU Quad-Core A53, 1GB de memoria DDR3 y 32GB de almacenamiento eMMC para ofrecer un funcionamiento fluido. Su pantalla táctil permite consultar la dirección IP del dispositivo de un vistazo y realizar tareas básicas como la configuración de Wi-Fi.

Para la conectividad, admite Wi-Fi 6 de doble banda, estable y de alta velocidad, y transmisión directa de vídeo sin pérdida de señal, además de salida de vídeo 4K@30FPS para una imagen de alta definición durante el control remoto. Comet Pro es una opción destacada para gestionar dispositivos remotos de forma eficiente, tanto para uso personal como profesional.
