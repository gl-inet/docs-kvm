## Pantalla táctil {#touchscreen}

| Pantalla | Descripción |
| :-------------------------------- | :------------------ |
| ![inicio](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **Inicio**<br>Encienda Comet Pro. Aparecerá el logotipo de GL.iNet y, a continuación, una barra de progreso de inicio. Cuando la barra se complete, el dispositivo habrá terminado de arrancar. |
| ![contraseña de pantalla](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **Configurar la contraseña de pantalla**<br>Establezca una contraseña de pantalla para Comet Pro para proteger su privacidad. |
| ![configurar la red](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **Configurar la red**<br>Conecte Comet Pro a una red Wi-Fi de 2.4GHz/5GHz o a un dispositivo de red, como un router, un switch de red o una toma Ethernet, mediante un cable Ethernet. |
| ![pantalla de inicio](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **Pantalla de inicio**<br>**Arriba a la izquierda**: Estado de la nube y de la red.<br>**Arriba a la derecha**: Hora del sistema.<br>**Centro**: Dirección IP del dispositivo (solo se muestra cuando hay conexión a Internet).<br>**Parte inferior**: Señal de teclado y ratón, señal HDMI y estado de la conexión USB. |
| ![ajustes básicos](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **Ajustes básicos**<br>En la pantalla de inicio, deslice el dedo desde la derecha hacia la izquierda para acceder a los ajustes básicos, que incluyen **Screen Display**, **Wi-Fi** y **Cloud Service**. |
| ![acciones del sistema](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **Menú del sistema**<br>En la pantalla de inicio, deslice el dedo desde arriba hacia abajo para acceder al menú del sistema, que incluye **Reboot** y **Lock Screen**. |
| ![hora](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **Pantalla de bloqueo**<br>La pantalla de bloqueo muestra la fecha y la hora. |
| ![restablecimiento](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Restablecer los valores de fábrica**<br>Con el KVM encendido, introduzca una punta en el orificio de restablecimiento y manténgala presionada durante 8 segundos para restablecer los valores de fábrica. Retire la punta antes de que transcurran 8 segundos para cancelar el restablecimiento. |

## Contenido del paquete {#package-contents}

- 1 x Comet Pro (GL-RM10)
- 1 x Manual de usuario
- 1 x Tarjeta de agradecimiento
- 1 x Cable Ethernet
- 2 x Cable HD
- 1 x Cable USB (Type-A a Type-C)
- 1 x Cable USB (Type-C a Type-C)
- 1 x Adaptador de alimentación USB-A
- 1 x Adaptador de enchufe (según el país de envío)
