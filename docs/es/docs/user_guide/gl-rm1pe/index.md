# Guía de usuario de Comet PoE (GL-RM1PE) {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) es la versión con alimentación a través de Ethernet de [Comet (GL-RM1)](../gl-rm1/index.md), diseñada para simplificar la instalación con un solo cable. El modelo PoE recibe alimentación y conectividad de red mediante un único cable Ethernet, lo que reduce el cableado y facilita la instalación, especialmente en lugares de difícil acceso.

Además, esta versión amplía la capacidad EMMC a 32GB, lo que permite gestionar mejor registros del sistema, grabaciones o firmware personalizado.
