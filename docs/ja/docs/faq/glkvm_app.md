# GLKVM アプリ

![GLKVM app icon](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

GLKVM アプリは、GL.iNet の KVM に接続されているデバイスのリモート アクセスと制御用に設計された Windows および macOS アプリケーションであり、離れたマシンに直接アクセスする必要がある IT プロフェッショナル、リモート ワーカー、およびパワー ユーザーに最適です。

macOS ユーザーの場合は、[こちら ](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"} からダウンロードしてください。

Windows ユーザーの場合は、[こちら](https://www.gl-inet.com/app-rm/){target="_blank"}からダウンロードしてください（Windows 10 以降のみ）。

Android ユーザーの方は、[こちら ](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"} からダウンロードしてください。

iOSをお使いの場合は、[App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"}からダウンロードしてください。

または、Web ブラウザ経由のリモート アクセスにクラウド サービスを使用することもできます。詳細は[こちら](remote_access_via_cloud.md)をクリックしてください。
