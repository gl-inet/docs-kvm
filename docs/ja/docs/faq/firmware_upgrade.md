# KVM のファームウェアをアップグレードする方法

ファームウェアのアップグレードにより、新機能が追加され、デバイスの安定性が向上します。アップグレードを完了するには、以下の手順に従ってください。

1. KVM コンソールにログインし、右上隅にあるファームウェア バージョンをクリックしてアップデートを確認します。

    ![upgrade](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. 新しいファームウェアが利用可能な場合は、ポップアップ ウィンドウで**オンライン アップグレード**を実行できます。そうでない場合、KVM のファームウェアは最新です。

    ![up-to-date](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. **Update Settings** をクリックして、ローカル アップグレードを実行するか、ベータ プログラムに参加するか、現在の構成を保存します。

    ![update settings](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade**: ローカル アップグレードを実行する前に、[ファームウェア ダウンロード センター](https://dl.gl-inet.com/kvm){target="_blank"} から最新のファームウェアをダウンロードしてください。

    - **Join Beta Program**: ベータ ファームウェアでは、今後の機能に早期にアクセスできます。ベータ版は不安定な可能性があり、デバイスのパフォーマンスに影響を与える可能性があることに注意してください。プレリリース ソフトウェアのテストに抵抗がない場合のみご参加ください。

    - **現在の構成を保存**: クラウド サービス アカウントへのバインドが保存されます。
