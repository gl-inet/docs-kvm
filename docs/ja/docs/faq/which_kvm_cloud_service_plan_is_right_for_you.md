# KVM Cloud のプランの選び方

KVM Cloud サービスには、無料の Standard プランと有料の Advanced プランがあります。スクリーンウォールとデバイス共有は、Advanced プランでのみ利用できるプレミアム機能です。以下の表で各プランの機能を比較できます。必要に応じて Advanced プランにアップグレードしてください。

## 機能比較

| 主な機能 | Standard | Advanced |
| ---- | ---- | ---- |
| 基本接続 | ✓ 基本接続を継続して利用可能 | ✓ 基本接続を継続して利用可能 |
| バインド済みデバイス | ✓ アカウントに登録できる台数は無制限 | ✓ アカウントに登録できる台数は無制限 |
| スクリーンウォール | <span style="color:red;">✗</span> <span style="color:#888;">非対応</span> | ✓ 最大 **9** 台を追加可能 |
| デバイス共有 | <span style="color:red;">✗</span> <span style="color:#888;">非対応</span> | ✓ 最大 **5** 人のユーザーと共有可能 |
| リモートアクセス経路 | ✓ デバイスごとに有効な経路は 1 つ | ✓ デバイスごとに複数の経路を同時に利用可能 |
| 接続済みデバイスへのアクセス | ✓ 台数制限なし | ✓ 台数制限なし |

**注:** リモートアクセス経路は GLKVM Cloud とアプリに適用されます。
