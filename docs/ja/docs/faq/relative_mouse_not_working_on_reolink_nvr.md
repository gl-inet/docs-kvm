# Reolink NVR で相対マウス モードが機能しない場合はどうすればよいですか

GL.iNet KVM を使用して Reolink NVR (特にデュアル マウスをサポートしていないモデル) または特定のビンテージ コンピューター (USB インターフェイスのないコンピューターなど) を制御する場合、相対マウス モードが機能しない可能性があります。一般的な問題には、モードが完全に失敗する、マウスの動きは追跡できるがクリックが反応しないなどがあります。

この問題は主に、KVM のマウス シミュレーションと Reolink NVR などのデバイスの制限された機能の間の互換性の問題に起因します。

- **ファームウェア v1.4.0** より前: KVM は 1 つのマウスのみをシミュレートするように設計されています。相対モードと絶対モードを切り替えるには、KVM を再起動する必要がありますが、これはほとんどのヴィンテージまたは特殊なデバイスで正常に機能しました。

- **ファームウェア v1.4.0** 以降: 再起動せずにシームレスなモード切り替えを有効にするために、2 つのマウス (1 つは相対モード、もう 1 つは絶対モード) を同時にシミュレートするようにデフォルトのロジックが更新されました。ただし、Reolink NVR と一部のビンテージ コンピューターはデュアル マウスをサポートしていないため、次の 2 つの一般的な問題が発生します。

    - 相対マウス モードがまったく機能しません。
    - マウスは引き続き追跡しますが、クリックしても反応しません。

この問題を解決するには、端末で相対マウス モードを強制します。次の手順に従います。

1. KVM コンソールにアクセスし、**Toolbox** -> **Terminal** に移動します。 [**Access**] をクリックして、KVM 端子を入力します。

2. 次のコマンドで構成ファイルを開きます。

    `vi /etc/kvmd/override.yaml`

3. 次のコマンドを実行して、相対マウス モードを強制します。

    ```
    kvmd:
        hid:
            mouse:
                absolute: false
    ```

4. ファイルを保存し、エディタを終了します。

5. KVM デバイスを再起動して、変更を適用します。

!!! note

    1. 上記の方法が機能しない場合は、KVM ファームウェアを、シングル マウス エミュレーションをサポートし、古いデバイスと互換性のある v1.4 より前のバージョン (利用可能な場合) にロールバックしてみてください。

    2. Mac OS 用のスタンドアロン GLKVM アプリは、ブラウザー カーネルの制限 (requestPointerLock API サポートの欠如) のため、相対マウス モードをサポートしません。代わりに Web コンソールを使用してください。
