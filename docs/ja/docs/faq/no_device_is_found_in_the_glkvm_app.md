# GLKVM アプリでデバイスが見つからない場合はどうすればよいですか

KVM デバイスを初めて追加するときに、**Auto Discover** を選択すると、GLKVM アプリに **デバイスが見つかりません** と表示される場合があります。

![no device found](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

トラブルシューティングのヒントをいくつか紹介します。

1. 電源入力用の Type-C ケーブル、HDMI ケーブル、イーサネット ケーブル (必要な場合)、USB-A ケーブルを含むすべてのケーブルが KVM デバイスに正しく接続されていることを確認します。

2. KVM がインターネットに接続されていることを確認してください。 LED が白色に点灯している場合は、ネットワーク接続が正常であることを示します。

3. KVM と制御側デバイスが同じネットワークに接続されていることを確認してください。
