# Comet 5G (GL-RM10RC) ユーザーガイド

Comet 5G (GL-RM10RC) は、5G RedCap 対応のリモート KVM で、セルラー接続を統合して、有線ネットワーク アクセスのないエリアでも完全なデバイス制御を提供し、導入の柔軟性を大幅に高めます。 5G RedCap、Wi-Fi 6、およびイーサネット フェイルオーバーをサポートし、さまざまなネットワーク条件下で接続を維持します。

内蔵タッチスクリーンを備えているため、設定と日常の操作が簡素化され、リモート管理用のシンプルで効率的なインターフェイスが提供されます。 ATX ボードやフィンガーボットなどの拡張機能と併用すると、接続された機器の電源オンおよび電源オフをリモートで制御できるため、分散管理やフィールド メンテナンスのシナリオに最適です。
