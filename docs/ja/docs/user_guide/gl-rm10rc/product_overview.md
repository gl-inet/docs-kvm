## ハイライト

1. **5G RedCap**

    Comet 5G は、最先端の 5G RedCap テクノロジーを統合して柔軟なインターネット アクセスを提供し、固定オンサイト ネットワークの制約から導入を解放します。

2. **Network Failover**

    統合されたセルラー接続、Wi-Fi 6、およびイーサネット フェイルオーバー サポートと組み合わせることで、Comet 5G は継続的な稼働時間を保証します。 1 つの接続に障害が発生した場合、次の利用可能なネットワークにシームレスかつ自動的に切り替わり、困難な状況でもリモート KVM の操作が中断されることはありません。

3. **Dual-Band Wi-Fi 6**

    Comet 5G はデュアルバンド Wi-Fi 6 (2.4GHz および 5GHz) をサポートし、リモート操作とデータ アクセスに高速、低遅延、安定したワイヤレス接続を提供します。

4. **Nearby Control via AP Mode**

    Comet 5G は Wi-Fi Nearby Control を備えており、有線接続を使用せずに迅速なローカル管理を可能にします。 Comet 5G の Wi-Fi ネットワーク モードを AP モードに切り替えるだけで、固有の Wi-Fi SSID が生成されます。 Comet 5G のコンソールに安全にアクセスするには、この SSID に接続します。

    **Note**: AP モードをアクティブにすると、Comet 5G がアップストリーム Wi-Fi から切断され、近くのアクセスのみが提供されます (インターネット接続なし)。

5. **Browser-Based Remote Access**

    Comet 5G を使用すると、Web ブラウザを通じてコンソールに直接アクセスできるため、クライアントのインストールが不要になります。このブラウザベースのアクセスでは、安全な HTTPS 暗号化が使用され、自己署名証明書の警告が回避され、追加のソフトウェアを必要とせずに安全かつ簡単な接続が保証されます。

6. **洗練されたデザインとタッチスクリーン**

    Comet 5G は、滑らかな輪郭、丸い角、耐久性と高級感の両方を提供する質感のあるマット仕上げを備えたダークグレーのボディを備えています。 3.69 インチ TFT タッチスクリーンは、デバイス機能に素早くアクセスできる直感的なインターフェイスを提供し、シームレスなユーザー エクスペリエンスを保証します。

7. **4K Display & Two-Way Audio**

    Comet 5G は、HDMI アウト パススルーを使用して最大 4K@30FPS のビデオ出力をサポートし、外部スプリッターなしでローカル表示とリモート アクセスを同時に行うことができます。双方向音声機能も備えており、ビデオ会議や遠隔技術指導でのクリアなコミュニケーションが可能になります。

8. **Self-Hosted Deployment**

    Comet 5G は、Linux や Ubuntu などの主流オペレーティング システム上での柔軟なセルフホスト展開を可能にし、リモート アクセスとデータ プライバシーを完全に制御できます。セルフホステッド システムには、少なくともデュアルコア CPU と 2GB のメモリを備えたクラウド サーバーが必要で、プライバシーと信頼性の高い操作の両方が保証されます。

9. **Remote Power Control**

    Comet 5G は、ATX ボードや Fingerbot などの外部デバイスを接続するための USB ポートを提供し、接続された機器のリモート電源制御を可能にします。

    **Note**: オプションのアクセサリは別売りです。

## 周波数バンド

Comet 5G は次の周波数帯域をサポートします。

- **5G NR**

    3GPP リリース 17 RedCap、SA 動作 (Sub-6 GHz) n1 / n2 / n3 / n5 / n7 / n8 / n12 / n13 / n14 / n18 / n20 / n25 / n26 / n28 / n30 / n38 / n40 / n41 / n48 / n66 / n70 / n77 / n78 / n79

- **LTE FDD**

    B1 / B2 / B3 / B4 / B5 / B7 / B8 / B12 / B13 / B14 / B17 / B18 / B19 / B20 / B25 / B26 / B28 / B30 / B66 / B70

- **LTE TDD**

    B34 / B38 / B39 / B40 / B41 / B42 / B43 / B48

- 1×Comet 5G (GL-RM10RC)

- 1 x サンキューカード
- 1 x イーサネット ケーブル
- 1×HDMIケーブル
- 1 x USB ケーブル (Type-A - Type-C)
- 1 x 電源アダプター
