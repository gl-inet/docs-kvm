## LED

Comet PoE の上部パネルには LED インジケーターが 1 つあります。

| LED ステータス |説明 |
| :----------------------- | :-------------------------------- |
|青一色 |起動中 |
|白く点滅 |起動したがインターネットに接続できない |
|ソリッドホワイト |インターネットに接続しています |
|青と白の点滅 |ファームウェアのアップグレード |

## パッケージ内容

- 1×Comet PoE(GL-RM1PE)
- 1 x ユーザーマニュアル
- 1 x イーサネット ケーブル
- 1 x HD ケーブル
- 1 x USB ケーブル (Type-A - Type-C)
- 1 x USB ケーブル (Type-C - Type-C)
