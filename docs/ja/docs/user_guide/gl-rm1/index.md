# Comet (GL-RM1) V1/V2 ユーザーガイド

Comet (GL-RM1) V1/V2 は、幅広いアプリケーションを備えたリモート KVM デバイスです。これを使用すると、外出先から自宅のコンピュータをリモート コントロールしたり、ローカル リソースにアクセスしたりできます。オフライン デバイスのリモート コントロールをサポートしているため、コンピュータの起動障害に対処したり、BIOS 設定を調整したりできます。リモートファイル転送機能も備えており、オンライン・オフラインのパソコン間でも簡単にデータ転送が可能です。音声サポートにより、より没入型のリモート インタラクション エクスペリエンスが提供されます。つまり、リモートワークやデバイス管理に欠かせないツールです。
