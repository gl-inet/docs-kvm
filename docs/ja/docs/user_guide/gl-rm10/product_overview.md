## タッチスクリーン

|画面表示 |説明 |
| :-------------------------------- | :------------------ |
| ![booting](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **起動中**<br>Comet Pro の電源を入れます。 GL.iNet ロゴが表示され、その後に起動進行状況バーが表示されます。プログレスバーが完全に読み込まれると、デバイスの起動が完了します。 |
| ![screen password](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **画面パスワードを設定します**<br>プライバシーを保護するために、Comet Pro の画面パスワードを設定します。 |
| ![setup network](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **ネットワークのセットアップ**<br>Comet Pro を 2.4GHz/5GHz Wi-Fi に接続するか、イーサネット ケーブルを介してネットワーク デバイス (ルータ、ネットワーク スイッチ、イーサネット ジャックなど) に接続します。 |
| ![home](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **ホーム画面**<br>**Top-left**: クラウドとネットワークのステータス。<br>**Top-right**: システム時間。<br>**Middle**: デバイスの IP アドレス (インターネット接続時にのみ表示)。<br>**Bottom**: キーボードとマウスの信号、 HDMI信号、USB接続状態。 |
| ![basic settings](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **基本設定**<br>ホーム画面で右から左にスワイプして、**Screen Display**、**Wi-Fi**、**Cloud Service** などの基本設定にアクセスします。 |
| ![system actions](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **System Menu**<br>ホーム画面で上から下にスワイプして、**Reboot** や **Lock Screen** などのシステム メニューにアクセスします。 |
| ![time](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **ロック画面**<br>ロック画面には時刻と日付が表示されます。 |
| ![reset](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Factory Reset**<br>KVM の電源が入っている状態で、ピンをリセット ピンホールに挿入し、8 秒間押し続けて工場出荷時設定にリセットします。リセットをキャンセルするには、8 秒以内にピンを放します。 |

## パッケージ内容

- 1×Comet Pro(GL-RM10)
- 1 x ユーザーマニュアル
- 1 x サンキューカード
- 1 x イーサネット ケーブル
- 2×HDケーブル
- 1 x USB ケーブル (Type-A - Type-C)
- 1 x USB ケーブル (Type-C - Type-C)
- 1 x USB-A 電源アダプター
- 1 x コンバーター (配送国に基づく)
