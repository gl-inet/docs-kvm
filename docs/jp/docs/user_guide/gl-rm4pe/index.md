# Comet X (GL-RM4PE) ユーザーガイド

Comet X は、ラック内の最大 4 台のサーバーに接続する PoE サポートを備えたクアッドポート リモート KVM です。セットアップが完了すると、接続されているすべてのデバイスをどこからでもブラウザまたはアプリ経由で制御でき、追加のソフトウェアを使用せずにスムーズな 4K@30fps ビデオを配信できます。内蔵の 3.69 インチ タッチスクリーンにより、IP アドレス、オンライン ステータス、アクティブなセッションを一目で確認できます。 PoE 電力による導入が簡素化され、サーバー環境内のケーブルの煩雑さが軽減されます。 64GB eMMC ストレージは ISO ファイルの組み込みリポジトリとしても機能し、OS の導入と緊急時のリカバリが容易になります。
