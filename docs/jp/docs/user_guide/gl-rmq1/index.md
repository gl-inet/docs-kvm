# Comet Q (GL-RMQ1) ユーザーガイド

Comet Q は、USB‑C を介して携帯電話、Mac mini、またはラップトップに接続できる手のひらサイズのデバイスです。接続したら、ブラウザを開いてターゲット デバイスを完全に制御できます。追加のソフトウェアのインストールや複雑な構成は必要ありません。内蔵の 1.8 インチ タッチスクリーンにより、ユニットから直接セットアップ、ステータス チェック、デバイス上のアクション トリガーを行うことができます。

iPhone をサポートする世界初の KVM で、Windows PC から iOS デバイスのロックを解除、タップ、スワイプし、完全に操作できるようになります。これまでは利用できなかった機能です。
