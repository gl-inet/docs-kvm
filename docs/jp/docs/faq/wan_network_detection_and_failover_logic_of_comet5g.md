# WAN Comet 5G のネットワーク検出およびフェイルオーバー ロジックとは何ですか

1. システムは ping ベースの検出を使用し、**3 seconds** ごとにすべてのインターフェイスにプローブを送信し、**9 seconds** ごとにフェイルオーバー条件を評価します。  
   
2. 優先度の高いインターフェースへのすべての ping テストが **9 second** 期間内に失敗し、優先度の低いインターフェースが到達可能なままの場合、その期間後にフェイルオーバーがトリガーされます。すべてのインターフェイスが到達不能な場合、フェイルオーバーは発生しません。  
   
3. オフラインとしてマークされたインターフェイスは、引き続きバックグラウンド ping プローブを受信します。  
   
4. リカバリ: **9 seconds** 内で優先度の高いインターフェイスが ping 到達可能になった場合、システムはその期間後にそのインターフェイスに戻ります。
