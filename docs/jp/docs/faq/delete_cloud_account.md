# クラウド アカウントを削除する方法

セキュリティ上の理由から、クラウド アカウントが使用されなくなった場合は削除できます。

**WARNING**:

1. GL.iNet ルーターと KVM デバイスは、統合されたクラウド サービスを共有します。クラウド アカウントを削除すると、変更はルーターと KVM デバイスの両方に有効になります。
2. Deletion を実行すると、関連するすべてのサービス、データ、個人情報が完全に消去され、回復のオプションはありません。
3. 削除を続行する前に、すべての組織を脱退してください。

---

クラウド アカウントを削除するには、GLKVM アプリ経由またはクラウド経由の 2 つの方法があります。

必要に応じて、次の手順に従ってクラウド アカウントを削除します。

## GLKVM アプリで削除

1. GLKVM アプリにログインし、左上隅にあるプロフィールをクリックして、**Settings** をクリックします。

    ![app delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete1.png){class="glboxshadow"}

2. **Account**設定で、**Delete**ボタンをクリックします。すべてのデータが消去されます。慎重に作業を進めてください。

    ![app delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete2.png){class="glboxshadow"}
    
## クラウドで削除

1. コンピューターで Web ブラウザーを起動します (互換性を高めるために Chrome または Edge をお勧めします)。アドレスバーに「`glkvm.com`」と入力し、クラウドアカウントでログインします。

2. ログイン後、右上隅にあるプロフィールをクリックし、**Personal Center** をクリックします。

    ![cloud delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete1.png){class="glboxshadow"}

3. ページの一番下までスクロールし、**Delete** ボタンをクリックします。すべてのデータが消去されます。慎重に作業を進めてください。

    ![cloud delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete2.png){class="glboxshadow"}
