# リモート画面に BIOS インターフェイスが表示されない場合はどうすればよいですか

KVM 経由で被制御デバイスにアクセスするときに、リモート画面に BIOS インターフェイスが表示されない場合 (たとえば、HDMI 信号がありません)、その理由は、BIOS インターフェイスが通常、プライマリ モニターにのみ出力するためです。ここにいくつかの提案があります。

## ラップトップ

被制御デバイスがラップトップの場合、その内蔵画面がプライマリ ディスプレイとして機能するため、外部 KVM は BIOS インターフェイスをレンダリングできません。

## デスクトップ

デスクトップ デバイスの場合は、プライマリ モニターを DisplayPort ポートに接続します (利用可能な場合)。これは、ほとんどのグラフィックス カードとマザーボードが起動時に HDMI よりも DP 出力を優先するためです。

KVM 経由で BIOS インターフェイスを表示するには、以下の方法に従ってください。
    
- 異なるモニター ポートを切り替えます。 GL.iNet KVM を、コンピューターのプライマリ ディスプレイ出力として設定されているポートに接続します。
    
- 1 対 2 HDMI スプリッター (別売り) を使用して、プライマリ ディスプレイ信号を KVM デバイスに複製します。

> **Note**: BIOS 信号はプライマリ モニターにのみ送信され、リモート KVM 画面には表示されないため、この問題は、被制御デバイスが **Windows PE** で起動するときにも発生する可能性があります。

> 追加のモニターでテストすることをお勧めします。セカンダリ ディスプレイが依然として信号を受信できない場合、KVM は BIOS 画面をキャプチャできません。これを解決するには、ディスプレイ ドライバーを WinPE システムに手動で統合またはインストールすることができます。
