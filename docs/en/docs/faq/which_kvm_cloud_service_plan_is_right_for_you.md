# Which KVM Cloud service plan is right for you

KVM Cloud Service is available in two plans: the free Standard plan and the paid Advanced plan. Screen Wall and Device Sharing are premium features available only in the Advanced plan. The following table compares the features included in each plan. You can upgrade to the Advanced plan as needed.

## Benefits Comparison
| Key Function | Standard | Advanced |
| ---- | ---- | ---- |
| Basic Connection | ✓ Lifetime basic connection | ✓ Lifetime basic connection |
| Bound Devices | ✓ Unlimited devices under account | ✓ Unlimited devices under account |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">Not Supported</span> | ✓ Supports up to **9** additions |
| Device Sharing | <span style="color:red;">✗</span> <span style="color:#888;">Not Supported</span> | ✓ Supports sharing with up to **5** users |
| Remote Access Pathways | ✓ One active pathway per device | ✓ Multiple concurrent pathways per device |
| Connected Device Access | ✓ Unlimited devices | ✓ Unlimited devices |

**Note**: Remote Access Pathways apply to GLKVM Cloud and Apps.
