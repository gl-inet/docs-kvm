# How to set a static IP for KVM

This tutorial introduces the steps to set a static IP for your GL.iNet KVM directly on the console when its upstream router can't allocate one. 

Please select the appropriate steps according to your firmware version.

## Firmware v1.9 and earlier

The following steps take Comet (GL-RM1) as an example.

1. Log in to the Comet console and navigate to **Settings** -> **Network**. Click the IP address or right arrow icon.

    ![settings-network](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/settings-network.png){class="glboxshadow"}

2. Switch to **Static**. Enter an IP address within the subnet pool, along with the netmask, gateway and DNS servers for your Comet, then click **Confirm**.

    ![ethernet-settings-static](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet-settings-static.png){class="glboxshadow"}

## Firmware v1.10 and above

The following steps take Comet Pro(GL-RM10) as an example.

1. Log in to the Comet Pro console and click the Settings icon in the navigation bar to open the Settings page.

    ![setting network](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/setting_network.png){class="glboxshadow"}

2. Go to **Network**, click the **Static** button in Ethernet Settings. Enter an IP address within the subnet pool, along with the netmask, gateway and DNS servers for your Comet Pro, then click **Confirm**.

    ![ethernet settings static](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet_settings_static.png){class="glboxshadow"}
