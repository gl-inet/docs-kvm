# Comet Q (GL-RMQ1) – gebruikershandleiding {#comet-q-gl-rmq1-user-guide}

Comet Q is een apparaat ter grootte van een handpalm dat via USB-C wordt aangesloten op compatibele mobiele telefoons, Mac mini-computers en laptops (ondersteuning voor DP Alt Mode vereist). Na het aansluiten opent u een browser en hebt u volledige controle over het doelapparaat, zonder extra software of ingewikkelde configuratie. Met het ingebouwde touchscreen van 1,8" kunt u het apparaat snel instellen, de status controleren en acties rechtstreeks op het apparaat starten.

Het is de eerste KVM ter wereld die iPhones ondersteunt: u kunt een iOS-apparaat vanaf een Windows-pc ontgrendelen, erop tikken, vegen en het volledig bedienen – een functie die voorheen niet beschikbaar was.
