# Comet PoE (GL-RM1PE) – gebruikershandleiding {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) is de Power-over-Ethernet-versie van de [Comet (GL-RM1)](../gl-rm1/index.md), ontworpen voor een eenvoudige installatie met één kabel. Het PoE-model ontvangt zowel stroom als netwerkverbinding via één ethernetkabel. Dat beperkt het aantal kabels en vereenvoudigt de installatie, vooral op moeilijk bereikbare plaatsen.

Daarnaast is de eMMC-opslag in deze versie vergroot tot 32GB, zodat er meer ruimte is voor systeemlogboeken, opnamen of aangepaste firmware.
