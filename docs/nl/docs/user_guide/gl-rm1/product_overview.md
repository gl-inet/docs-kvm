## Led {#led}

Op het bovenpaneel van de Comet bevindt zich een ledindicator.

| Ledstatus                | Beschrijving                      |
| :----------------------- | :-------------------------------- |
| Blauw, brandt continu    | Bezig met opstarten               |
| Wit, knippert            | Opgestart, maar geen internet     |
| Wit, brandt continu      | Verbonden met internet            |
| Blauw en wit, knippert   | Firmware-upgrade bezig            |

## Knop {#button}

Op het zijpaneel van de Comet bevindt zich een knop.

| Functie                    | Bediening                                | Ledstatus                             |
| :------------------------- | :--------------------------------------- | :------------------------------------ |
| U-Boot-flashmodus starten  | Houd de knop bij ingeschakeld apparaat <br>langer dan **3s** ingedrukt en laat deze dan los | Tijdens het indrukken: blauw knipperend <br>U-Boot-modus gestart: blauw, brandt continu |
| Reset                      | Houd de knop bij ingeschakeld apparaat <br>**8–20s** ingedrukt en laat deze dan los        | 1-8s ingedrukt: knippert langzaam <br>8-20s ingedrukt: knippert snel |

## Inhoud van de verpakking {#package-contents}

- 1 x Comet (GL-RM1)
- 1 x gebruikershandleiding
- 1 x bedankkaart
- 1 x ethernetkabel
- 1 x HD-kabel
- 1 x USB-kabel (Type-A naar Type-C)
- 1 x USB-kabel (Type-C naar Type-C)

!!! Warning "Waarschuwing"

    PD-adapters kunnen niet worden gebruikt.
