# Comet (GL-RM1) V1/V2 – gebruikershandleiding {#comet-gl-rm1-v1v2-user-guide}

Comet (GL-RM1) V1/V2 is een extern KVM-apparaat met een breed scala aan toepassingen. Hiermee kunt u uw thuiscomputer op afstand bedienen wanneer u niet thuis bent, lokale bronnen gebruiken en meer. Het apparaat ondersteunt het op afstand bedienen van offline apparaten, zodat u opstartproblemen van een computer kunt oplossen en BIOS-instellingen kunt aanpassen. Daarnaast beschikt het over een functie voor externe bestandsoverdracht, waarmee u eenvoudig gegevens kunt overzetten naar zowel online als offline computers. Dankzij de audio-ondersteuning biedt het een meeslepende ervaring bij werken op afstand. Kortom: een onmisbaar hulpmiddel voor werken op afstand en apparaatbeheer.
