# De cloudgebaseerde Screen Wall-functie gebruiken {#how-to-use-the-cloud-based-screen-wall-feature}

De cloudgebaseerde Screen Wall is een premiumfunctie waarmee u de schermen van meerdere apparaten op één pagina kunt bekijken en eenvoudig hun status kunt volgen.

**Opmerking:** Voer een upgrade uit van de firmware van uw KVM naar versie 1.7 voordat u deze functie gebruikt.

Volg de onderstaande stappen om de cloudgebaseerde Screen Wall te gebruiken.

1. Koppel uw KVM-apparaat aan de cloud. Zie [Uw KVM aan de cloud koppelen](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud) voor meer informatie.

    ![Aanmelden bij de cloud](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/cloud_login.png){class="glboxshadow"}

2. Meld u na het koppelen aan bij [https://glkvm.com/](https://glkvm.com/){target="_blank"}. Uw gekoppelde apparaten verschijnen in de apparatenlijst. Zorg ervoor dat de apparaten online zijn.

    ![Apparatenlijst](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/device_list.png){class="glboxshadow"}

3. Klik in het menu links op **Screen Wall** en klik op **Setup Screen Wall**.

    ![Screen Wall](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/setup_screen_wall.png){class="glboxshadow"}

4. Selecteer de KVM-apparaten die u op de Screen Wall wilt bekijken en klik rechtsboven op **Save Screen Wall**.

    ![Apparaat selecteren](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/select_device.png){class="glboxshadow"}

    **Opmerking:** Als op uw apparaat firmware ouder dan versie 1.7 draait, wordt het apparaat grijs weergegeven en kan het niet worden geselecteerd. Voer eerst een upgrade van de firmware uit voordat u deze functie gebruikt.

5. Nadat de instellingen zijn opgeslagen, wordt via de cloud verbinding gemaakt met het geselecteerde apparaat.

    ![Verbinding maken](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/connecting.png){class="glboxshadow"}

6. Voer na het verbinden voor elk van uw KVM-apparaten het beheerderswachtwoord in.

    ![Aanmelden als beheerder](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/admin_login.png){class="glboxshadow"}

7. Daarna kunt u de schermen van meerdere apparaten op één pagina bekijken.

    ![Weergave van de Screen Wall](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/screen_wall_display.png){class="glboxshadow"}
