# Welk KVM Cloud-abonnement past bij u? {#which-kvm-cloud-service-plan-is-right-for-you}

KVM Cloud Service is beschikbaar in twee abonnementen: het gratis abonnement Standard en het betaalde abonnement Advanced. Screen Wall en Device Sharing zijn premiumfuncties die alleen beschikbaar zijn in het abonnement Advanced. In de volgende tabel worden de functies van beide abonnementen vergeleken. U kunt naar behoefte upgraden naar het abonnement Advanced.

## Vergelijking van de voordelen {#benefits-comparison}
| Belangrijkste functie | Standard | Advanced |
| ---- | ---- | ---- |
| Basisverbinding | ✓ Levenslange basisverbinding | ✓ Levenslange basisverbinding |
| Gekoppelde apparaten | ✓ Onbeperkt aantal apparaten per account | ✓ Onbeperkt aantal apparaten per account |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">Niet ondersteund</span> | ✓ Maximaal **9** toevoegingen |
| Apparaten delen | <span style="color:red;">✗</span> <span style="color:#888;">Niet ondersteund</span> | ✓ Delen met maximaal **5** gebruikers |
| Paden voor externe toegang | ✓ Eén actief pad per apparaat | ✓ Meerdere gelijktijdige paden per apparaat |
| Toegang tot aangesloten apparaten | ✓ Onbeperkt aantal apparaten | ✓ Onbeperkt aantal apparaten |

**Opmerking**: Paden voor externe toegang gelden voor GLKVM Cloud en de apps.
