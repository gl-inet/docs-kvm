# Så fångar du text från fjärrskärmen {#how-to-capture-text-from-the-remote-screen}

Med funktionen för textigenkänning kan du markera ett område på fjärrskärmen och enkelt extrahera text. Funktionen bygger på optisk teckenigenkänning (OCR) och introducerades i firmware v1.9.0.

Med den här funktionen kan du enkelt fånga text från fjärrskärmen (dvs. den styrda enheten) och kopiera den till den styrande enheten.

Följ stegen nedan för att fånga text från fjärrskärmen.

## Firmware v1.10 och senare {#firmware-v110-and-above}

1. Logga in på KVM-konsolen och gå till **Toolbox** -> **OCR**. Klicka på nedåtpilen för att välja önskat igenkänningsspråk, till exempel kinesiska, engelska eller tvåspråkigt (Zh/En).

    ![OCR-igenkänning 1](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_1.png){class="glboxshadow"}

2. Klicka på **Capture**, så tonas fjärrskärmen ned. Om du vill avsluta textfångsten klickar du på **Cancel**.

    ![OCR-igenkänning 2](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_2.png){class="glboxshadow"}

3. Rita en ruta runt texten som du vill extrahera, enligt bilden nedan.

    ![OCR-igenkänning 3](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_3.png){class="glboxshadow"}

4. Systemet identifierar automatiskt texten i det markerade området. Därefter kan du kopiera den igenkända texten efter behov.

    ![OCR-igenkänning 4](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_4.png){class="glboxshadow"}

## Firmware v1.9.x {#firmware-v19x}

1. Logga in på KVM-konsolen. Klicka på nedåtpilen för att välja önskat igenkänningsspråk, till exempel kinesiska, engelska eller tvåspråkigt (Zh/En).

    ![Textigenkänning 1](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/1.png){class="glboxshadow"}

2. Klicka på ikonen **"T"** högst upp i mitten av verktygsfältet, så tonas fjärrskärmen ned.

    ![Textigenkänning 2](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/2.png){class="glboxshadow"}

3. Rita en ruta runt texten som du vill extrahera, enligt bilden nedan.

    ![Textigenkänning 3](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/3.png){class="glboxshadow"}

4. Systemet identifierar automatiskt texten i det markerade området. Därefter kan du kopiera den igenkända texten efter behov.

    ![Textigenkänning 4](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/4.png){class="glboxshadow"}
