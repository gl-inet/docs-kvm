# Så använder du den molnbaserade funktionen Screen Wall {#how-to-use-the-cloud-based-screen-wall-feature}

Den molnbaserade funktionen Screen Wall är en premiumfunktion som låter dig visa skärmarna från flera enheter på en och samma sida och enkelt hålla koll på deras status.

**Obs!** Uppgradera KVM-enhetens firmware till version 1.7 innan du använder den här funktionen.

Följ stegen nedan för att använda den molnbaserade funktionen Screen Wall.

1. Koppla din KVM-enhet till molnet. Mer information finns i [Koppla din KVM till molnet](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud).

    ![Inloggning i molnet](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/cloud_login.png){class="glboxshadow"}

2. Logga in på [https://glkvm.com/](https://glkvm.com/){target="_blank"} när kopplingen är klar. Dina kopplade enheter visas i enhetslistan. Kontrollera att enheterna är online.

    ![Enhetslista](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/device_list.png){class="glboxshadow"}

3. Klicka på **Screen Wall** i menyn till vänster och klicka på **Setup Screen Wall**.

    ![Screen Wall](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/setup_screen_wall.png){class="glboxshadow"}

4. Välj de KVM-enheter som du vill visa på Screen Wall och klicka på **Save Screen Wall** i det övre högra hörnet.

    ![Välj enhet](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/select_device.png){class="glboxshadow"}

    **Obs!** Om enheten kör firmware som är äldre än version 1.7 är den nedtonad och kan inte väljas. Uppgradera först firmwaren innan du använder den här funktionen.

5. När inställningarna har sparats börjar anslutningen till de valda enheterna via molnet.

    ![Ansluter](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/connecting.png){class="glboxshadow"}

6. När anslutningen är upprättad anger du administratörslösenordet för var och en av dina KVM-enheter.

    ![Administratörsinloggning](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/admin_login.png){class="glboxshadow"}

7. Därefter kan du se skärmarna från flera enheter på en och samma sida.

    ![Visning på Screen Wall](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/screen_wall_display.png){class="glboxshadow"}
