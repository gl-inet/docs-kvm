# Så delar du KVM-enheter med andra {#how-to-share-kvm-devices-with-others}

Molnbaserad enhetsdelning är en premiumfunktion som låter dig ge andra användare fjärråtkomst till dina KVM-enheter och hantera deras behörigheter på distans.

**Obs!** Uppgradera KVM-enhetens firmware till version 1.7 innan du använder den här funktionen.

Följ stegen nedan för att dela en KVM-enhet med andra.

1. Koppla din KVM-enhet till molnet. Mer information finns i [Koppla din KVM till molnet](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud).

    ![Inloggning i molnet](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/cloud_login.png){class="glboxshadow"}

2. Logga in på [https://glkvm.com/](https://glkvm.com/){target="_blank"} när kopplingen är klar. Dina kopplade enheter visas i enhetslistan. Kontrollera att enheterna är online.

    ![Enhetslista](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/device_list.png){class="glboxshadow"}

3. Klicka på menyn med tre punkter på enhetskortet och klicka på **Share Device**.

    ![Dela enhet 1](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_1.png){class="glboxshadow"}

4. Ange e-postadressen eller användarnamnet för den registrerade användare som du vill dela med och klicka sedan på **Invite**.

    ![Dela enhet 2](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_2.png){class="glboxshadow"}

    ![Dela enhet 3](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_3.png){class="glboxshadow"}

5. På mottagarens molnplattform visas dialogrutan Device Sharing Invitation. Klicka på **Accept**.

    ![Acceptera delning](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/accept_share.png){class="glboxshadow"}

    När inbjudan har accepterats kan mottagaren komma åt den delade enheten.

    ![Åtkomst till enheten](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/access_device.png){class="glboxshadow"}

6.  Du kan se delningsstatusen på molnplattformen.

    ![Delningen lyckades](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_successfully.png){class="glboxshadow"}

    Klicka på **Terminate** för att avsluta delningen. När delningen har avslutats har mottagaren inte längre åtkomst till den delade enheten.

    ![Avsluta](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/terminate.png){class="glboxshadow"}
