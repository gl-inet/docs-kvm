# Så exporterar du enhetsloggar och apploggar {#how-to-export-device-logs-and-app-logs}

Den här guiden beskriver hur du exporterar loggar från KVM-enheten och GLKVM-appen för felsökning.

## Enhetsloggar {#device-logs}

Logga in på KVM-konsolen, klicka på **Help** och välj **Export Log Files**.

![Enhetslogg](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/device_log.png){class="glboxshadow"}

## Apploggar {#app-logs}

Du kan exportera apploggar från skrivbordsappen eller mobilappen.

I skrivbordsappen loggar du in i GLKVM-appen, klickar på frågetecknet i det övre högra hörnet och väljer **Export Log**.

![Logg från skrivbordsappen](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/web_app_log.png){class="glboxshadow"}

I mobilappen loggar du in i GLKVM-appen, går till **Settings** -> **Help Center** och klickar på **Export Logs**.

![Logg från iOS-appen](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/ios_app_log.png){class="glboxshadow"}
