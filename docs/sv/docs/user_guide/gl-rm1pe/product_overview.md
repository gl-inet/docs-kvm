## Lysdiod {#led}

Det finns en lysdiodsindikator på ovansidan av Comet PoE.

| Lysdiodens status        | Beskrivning                       |
| :----------------------- | :-------------------------------- |
| Fast blått               | Startar                           |
| Blinkande vitt           | Startad men ingen internetanslutning |
| Fast vitt                | Ansluten till internet            |
| Blinkande blått och vitt | Firmware uppgraderas              |

## Förpackningens innehåll {#package-contents}

- 1 x Comet PoE (GL-RM1PE)
- 1 x Bruksanvisning
- 1 x Ethernet-kabel
- 1 x HD-kabel
- 1 x USB-kabel (Type-A till Type-C)
- 1 x USB-kabel (Type-C till Type-C)
