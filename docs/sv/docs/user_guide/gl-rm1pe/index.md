# Användarhandbok för Comet PoE (GL-RM1PE) {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) är versionen med Power over Ethernet av [Comet (GL-RM1)](../gl-rm1/index.md), utformad för enkla installationer med en enda kabel. PoE-modellen får både ström och nätverksanslutning via en enda Ethernet-kabel, vilket minskar kabeltrasslet och förenklar installationen, särskilt på svåråtkomliga platser.

Dessutom har den här versionen utökad eMMC-kapacitet på 32 GB, vilket gör den bättre lämpad för systemloggar, inspelningar eller anpassad firmware.
