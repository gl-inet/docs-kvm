# Användarhandbok för Comet Q (GL-RMQ1) {#comet-q-gl-rmq1-user-guide}

Comet Q är en enhet i handflatsstorlek som ansluts via USB-C till kompatibla mobiltelefoner, Mac mini-datorer och bärbara datorer (stöd för DP Alt Mode krävs). När den är ansluten kan du öppna en webbläsare och få full kontroll över målenheten, utan att installera extra programvara eller göra någon komplicerad konfiguration. Den inbyggda 1,8-tumspekskärmen gör att du snabbt kan konfigurera enheten, kontrollera status och utlösa åtgärder direkt på enheten.

Det är världens första KVM med stöd för iPhone, som låter dig låsa upp, trycka, svepa och använda en iOS-enhet fullt ut från en Windows-dator – en funktion som tidigare inte har funnits.
