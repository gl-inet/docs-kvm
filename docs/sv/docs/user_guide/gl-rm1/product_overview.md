## Lysdiod {#led}

Det finns en lysdiodsindikator på ovansidan av Comet.

| Lysdiodens status        | Beskrivning                        |
| :----------------------- | :-------------------------------- |
| Fast blått               | Startar                           |
| Blinkande vitt           | Startad men ingen internetanslutning |
| Fast vitt                | Ansluten till internet            |
| Blinkande blått och vitt | Firmware uppgraderas              |

## Knapp {#button}

Det finns en knapp på sidan av Comet.

| Funktion                   | Åtgärd                                   | Lysdiodens status                     |
| :------------------------- | :--------------------------------------- | :------------------------------------ |
| Gå till U-Boot-flashläge   | Håll knappen intryckt i mer än **3 s** <br>medan enheten är påslagen och släpp den sedan | Medan knappen hålls in: blinkande blått <br>I U-Boot-läge: fast blått      |
| Återställning              | Håll knappen intryckt i **8–20 s** <br>medan enheten är påslagen och släpp den sedan     | Vid 1–8 s: långsam blinkning <br>Vid 8–20 s: snabb blinkning |

## Förpackningens innehåll {#package-contents}

- 1 x Comet (GL-RM1)
- 1 x Bruksanvisning
- 1 x Tackkort
- 1 x Ethernet-kabel
- 1 x HD-kabel
- 1 x USB-kabel (Type-A till Type-C)
- 1 x USB-kabel (Type-C till Type-C)

!!! Warning "Varning"

    PD-adaptrar kan inte användas.
