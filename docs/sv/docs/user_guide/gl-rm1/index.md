# Användarhandbok för Comet (GL-RM1) V1/V2 {#comet-gl-rm1-v1v2-user-guide}

Comet (GL-RM1) V1/V2 är en fjärr-KVM-enhet med ett brett användningsområde. Med den kan du fjärrstyra din dator hemma när du är bortrest, komma åt lokala resurser med mera. Den stöder fjärrstyrning av enheter som inte är uppkopplade, så att du kan åtgärda problem vid datorstart och ändra BIOS-inställningar. Den har även en funktion för filöverföring på distans som gör det enkelt att överföra data till både uppkopplade och frånkopplade datorer. Med ljudstöd ger den en mer uppslukande upplevelse vid fjärrinteraktion. Kort sagt är den ett oumbärligt verktyg för distansarbete och enhetshantering.
