# Användarhandbok för Comet 5G (GL-RM10RC) {#comet-5g-gl-rm10rc-user-guide}

Comet 5G (GL-RM10RC) är en fjärr-KVM med stöd för 5G RedCap som integrerar mobilanslutning för fullständig enhetsstyrning, även i områden utan trådbunden nätverksåtkomst, vilket ger betydligt större flexibilitet vid installation. Den stöder 5G RedCap, Wi-Fi 6 och redundans (failover) via Ethernet för att upprätthålla anslutningen under varierande nätverksförhållanden.

Den inbyggda pekskärmen förenklar konfiguration och daglig drift och ger ett enkelt och effektivt gränssnitt för fjärrhantering. Tillsammans med tillbehör som ett ATX-kort eller en Fingerbot kan du fjärrstyra start och avstängning av ansluten utrustning, vilket gör den väl lämpad för distribuerad hantering och underhåll på plats.
