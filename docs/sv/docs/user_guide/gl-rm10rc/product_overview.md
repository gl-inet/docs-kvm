## Höjdpunkter {#highlights}

1. **5G RedCap**

    Comet 5G har den senaste 5G RedCap-tekniken för flexibel internetåtkomst, så att dina installationer inte är begränsade till fasta nätverk på plats.

2. **Nätverksredundans (failover)**

    Med integrerad mobilanslutning, Wi-Fi 6 och stöd för redundans via Ethernet säkerställer Comet 5G kontinuerlig drift. Om en anslutning går ned växlar den sömlöst och automatiskt till nästa tillgängliga nätverk, så att fjärr-KVM-driften kan fortsätta utan avbrott även under svåra förhållanden.

3. **Dubbelbandigt Wi-Fi 6**

    Comet 5G stöder dubbelbandigt Wi-Fi 6 (2,4 GHz och 5 GHz) och ger en snabb, stabil trådlös anslutning med låg latens för fjärrstyrning och dataåtkomst.

4. **Styrning på nära håll via AP-läge**

    Comet 5G har funktionen Wi-Fi Nearby Control, som möjliggör snabb lokal hantering utan trådbundna anslutningar. Växla bara Comet 5G:s Wi-Fi-nätverksläge till AP-läge, så skapar den ett unikt Wi-Fi-SSID. Anslut till detta SSID för att få säker åtkomst till Comet 5G:s konsol.

    **Obs!** När AP-läget aktiveras kopplas Comet 5G bort från sitt överordnade Wi-Fi-nätverk och ger endast åtkomst på nära håll (utan internetanslutning).

5. **Webbläsarbaserad fjärråtkomst**

    Med Comet 5G kan du komma åt konsolen direkt via en webbläsare, utan att installera någon klient. Den webbläsarbaserade åtkomsten använder säker HTTPS-kryptering och undviker varningar om självsignerade certifikat, vilket ger en säker och enkel anslutning utan extra programvara.

6. **Elegant design och pekskärm**

    Comet 5G har ett mörkgrått hölje med mjuka konturer, rundade hörn och en strukturerad matt yta som är både tålig och exklusiv. Den 3,69 tum stora TFT-pekskärmen ger ett intuitivt gränssnitt för snabb åtkomst till enhetens funktioner och en smidig användarupplevelse.

7. **4K-skärm och tvåvägsljud**

    Comet 5G stöder videoutgång upp till 4K@30FPS med HDMI-genomströmning, vilket ger samtidig lokal visning och fjärråtkomst utan extern splitter. Den har även tvåvägsljud för tydlig kommunikation vid videokonferenser eller teknisk vägledning på distans.

8. **Egen driftsättning (self-hosted)**

    Comet 5G kan driftsättas flexibelt på egna servrar med vanliga operativsystem, bland annat Linux och Ubuntu, vilket ger dig full kontroll över fjärråtkomsten och dataintegriteten. Det egeninstallerade systemet kräver en molnserver med minst en tvåkärnig processor och 2 GB minne, vilket säkerställer både integritet och tillförlitlig drift.

9. **Fjärrstyrning av ström**

    Comet 5G har en USB-port för anslutning av externa enheter som ett ATX-kort och en Fingerbot, vilket gör det möjligt att fjärrstyra strömmen till den anslutna utrustningen.

    **Obs!** Valfria tillbehör säljs separat.

## Frekvensband {#frequency-bands}

Comet 5G stöder följande frekvensband.

- **5G NR**

    3GPP Release 17 RedCap, SA-drift (Sub-6 GHz) n1 / n2 / n3 / n5 / n7 / n8 / n12 / n13 / n14 / n18 / n20 / n25 / n26 / n28 / n30 / n38 / n40 / n41 / n48 / n66 / n70 / n77 / n78 / n79

- **LTE FDD**

    B1 / B2 / B3 / B4 / B5 / B7 / B8 / B12 / B13 / B14 / B17 / B18 / B19 / B20 / B25 / B26 / B28 / B30 / B66 / B70

- **LTE TDD**

    B34 / B38 / B39 / B40 / B41 / B42 / B43 / B48
