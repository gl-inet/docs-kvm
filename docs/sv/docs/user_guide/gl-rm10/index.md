# Användarhandbok för Comet Pro (GL-RM10) {#comet-pro-gl-rm10-user-guide}

Comet Pro (GL-RM10) är en fjärr-KVM-lösning över Wi-Fi. Den drivs av en fyrkärnig A53-processor med 1 GB DDR3-minne och 32 GB eMMC-lagring för smidig prestanda. Med pekskärmen kan du snabbt se enhetens IP-adress och utföra grundläggande uppgifter som att konfigurera Wi-Fi.

För anslutning stöder den dubbelbandigt Wi-Fi 6 (stabilt och snabbt) och videogenomströmning (förlustfri signalöverföring), samt 4K@30FPS-videoutgång för HD-bild vid fjärrstyrning. Oavsett om det gäller privat eller professionellt bruk är Comet Pro ett förstklassigt val för effektiv fjärrhantering av enheter.
