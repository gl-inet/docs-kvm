## Pekskärm {#touchscreen}

| Skärmvisning                      | Beskrivning         |
| :-------------------------------- | :------------------ |
| ![Uppstart](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **Uppstart**<br>Slå på din Comet Pro. GL.iNet-logotypen visas, följd av en förloppsindikator för uppstarten. När förloppsindikatorn är full är enheten färdigstartad. |
| ![Skärmlösenord](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **Ställ in skärmlösenord**<br>Ställ in ett skärmlösenord för din Comet Pro för att skydda din integritet. |
| ![Konfigurera nätverk](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **Konfigurera nätverk**<br>Anslut Comet Pro till Wi-Fi på 2,4 GHz/5 GHz eller till en nätverksenhet (t.ex. router, nätverksswitch eller Ethernet-uttag) med en Ethernet-kabel. |
| ![Startskärm](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **Startskärm**<br>**Uppe till vänster**: moln- och nätverksstatus.<br>**Uppe till höger**: systemtid.<br>**Mitten**: enhetens IP-adress (visas bara när internet är anslutet).<br>**Nederst**: status för tangentbords- och mussignal, HDMI-signal och USB-anslutning. |
| ![Grundinställningar](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **Grundinställningar**<br>Svep åt vänster från högerkanten på startskärmen för att komma åt grundinställningarna, bland annat **Screen Display**, **Wi-Fi** och **Cloud Service**. |
| ![Systemmeny](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **Systemmeny**<br>Svep nedåt från överkanten på startskärmen för att komma åt systemmenyn, bland annat **Reboot** och **Lock Screen**. |
| ![Tid](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **Låsskärm**<br>Låsskärmen visar tid och datum. |
| ![Återställning](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Fabriksåterställning**<br>Medan KVM-enheten är påslagen sätter du in ett stift i återställningshålet och håller det intryckt i 8 sekunder för att återställa till fabriksinställningarna. Släpp stiftet inom 8 sekunder för att avbryta återställningen. |

## Förpackningens innehåll {#package-contents}

- 1 x Comet Pro (GL-RM10)
- 1 x Bruksanvisning
- 1 x Tackkort
- 1 x Ethernet-kabel
- 2 x HD-kabel
- 1 x USB-kabel (Type-A till Type-C)
- 1 x USB-kabel (Type-C till Type-C)
- 1 x USB-A-nätadapter
- 1 x Adapter (beroende på leveransland)
