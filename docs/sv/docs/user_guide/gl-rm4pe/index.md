# Användarhandbok för Comet X (GL-RM4PE) {#comet-x-gl-rm4pe-user-guide}

Comet X är en fjärr-KVM med fyra portar och PoE-stöd som kan anslutas till upp till 4 servrar i ditt rack. När den är installerad kan du styra alla anslutna enheter var du än befinner dig via en webbläsare eller app, med smidig 4K@30fps-video utan extra programvara. Den inbyggda 3,69-tumspekskärmen visar IP-adresser, onlinestatus och aktiva sessioner i en överblick. Strömförsörjning via PoE förenklar installationen och minskar kabeltrasslet i servermiljön. Den 64 GB stora eMMC-lagringen fungerar även som ett inbyggt arkiv för ISO-filer, vilket underlättar OS-installation och nödåterställning.
