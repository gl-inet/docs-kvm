# Så uppgraderar du KVM-enhetens firmware {#how-to-upgrade-your-kvms-firmware}

Firmwareuppgraderingar ger nya funktioner och förbättrar enhetens stabilitet. Följ stegen nedan för att slutföra uppgraderingen.

1. Logga in på KVM-konsolen och klicka på firmwareversionen i det övre högra hörnet för att söka efter uppdateringar.

    ![Uppgradering](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. Om det finns nyare firmware kan du göra en **onlineuppgradering** i popup-fönstret. Annars är KVM-enhetens firmware redan aktuell.

    ![Aktuell firmware](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. Klicka på **Update Settings** för att göra en lokal uppgradering, gå med i betaprogrammet eller spara den aktuella konfigurationen.

    ![Uppdateringsinställningar](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade**: ladda ned den senaste firmwaren från [Firmware Download Center](https://dl.gl-inet.com/kvm){target="_blank"} innan du gör en lokal uppgradering.

    - **Join Beta Program**: med betafirmware får du tidig tillgång till kommande funktioner. Observera att betaversioner kan vara instabila och påverka enhetens prestanda. Gå bara med om du är bekväm med att testa programvara som ännu inte har släppts.

    - **Save current configuration**: kopplingen till ditt konto för molntjänsten behålls.
