# Så kopplar du från KVM-enheten från molnet {#how-to-unbind-my-kvm-device-from-the-cloud}

Det finns tre sätt att koppla från KVM-enheter från molnet: via lokal åtkomst, GLKVM-appen eller molnet.

## Koppla från via lokal åtkomst {#unbind-via-local-access}

1. Kontrollera att datorn finns i samma lokala nätverk som KVM-enheten.

2. Starta en webbläsare på datorn (Chrome eller Edge rekommenderas för bättre kompatibilitet). Ange `glkvm.local` eller KVM-enhetens IP-adress i adressfältet för att öppna den lokala inloggningssidan för GLKVM. Ange administratörslösenordet för att logga in.

3. När du har loggat in går du till **Cloud Service** i det övre högra hörnet, klickar på kugghjulsikonen och väljer **Unbind**.

    ![Koppla från via lokal åtkomst](https://static.gl-inet.com/docs/kvm/faq/unbind/local_unbind.png){class="glboxshadow"}

## Koppla från via GLKVM-appen {#unbind-via-glkvm-app}

1. Logga in i GLKVM-appen och klicka på **Manage** i det övre högra hörnet av enheten.

    ![Koppla från via appen](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_1.png){class="glboxshadow"}

2. Klicka på **More** och välj **Unbind**.

    ![Frånkoppling i appen](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_2.png){class="glboxshadow"}

## Koppla från via molnet {#unbind-via-the-cloud}

1. Starta en webbläsare på datorn (Chrome eller Edge rekommenderas för bättre kompatibilitet). Ange `glkvm.com` i adressfältet och logga in med ditt molnkonto.

2. När du har loggat in klickar du på ikonen med tre punkter i det nedre högra hörnet av enheten och klickar på **Device Detail**.

    ![Koppla från via molnet](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_1.png){class="glboxshadow"}

3. Klicka på **Unbind** på informationssidan.

    ![Koppla från via molnet](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_2.png){class="glboxshadow gl-80-desktop"}
