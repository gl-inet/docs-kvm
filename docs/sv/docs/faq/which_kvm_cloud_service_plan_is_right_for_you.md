# Vilket abonnemang för KVM Cloud passar dig? {#which-kvm-cloud-service-plan-is-right-for-you}

KVM Cloud finns i två abonnemang: det kostnadsfria Standard och det betalda Advanced. Screen Wall och Device Sharing är premiumfunktioner som bara ingår i Advanced. Tabellen nedan jämför vilka funktioner som ingår i respektive abonnemang. Du kan uppgradera till Advanced vid behov.

## Jämförelse av förmåner {#benefits-comparison}
| Huvudfunktion | Standard | Advanced |
| ---- | ---- | ---- |
| Grundläggande anslutning | ✓ Grundläggande anslutning livet ut | ✓ Grundläggande anslutning livet ut |
| Kopplade enheter | ✓ Obegränsat antal enheter per konto | ✓ Obegränsat antal enheter per konto |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">Stöds inte</span> | ✓ Stöder upp till **9** tillagda enheter |
| Enhetsdelning | <span style="color:red;">✗</span> <span style="color:#888;">Stöds inte</span> | ✓ Stöder delning med upp till **5** användare |
| Vägar för fjärråtkomst | ✓ En aktiv väg per enhet | ✓ Flera samtidiga vägar per enhet |
| Åtkomst till anslutna enheter | ✓ Obegränsat antal enheter | ✓ Obegränsat antal enheter |

**Obs!** Vägar för fjärråtkomst gäller GLKVM Cloud och apparna.
