# Varför sparas inte mina inställningar för högtalare och mikrofon? {#why-cant-i-keep-my-speaker-and-microphone-settings}

Du kanske märker att om du aktiverar Speaker eller Microphone i KVM-konsolen (under Settings -> Remote Device Settings) behålls inte inställningarna när du startar om, loggar in på KVM-enheten igen eller uppdaterar webbsidan (vid lokal åtkomst).

I stället inaktiveras högtalaren automatiskt, och mikrofonen stängs av (ljudlös), även om den fortfarande visas som aktiverad efter att du har startat om enheten eller uppdaterat webbsidan.

![Inställningar för högtalare och mikrofon](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/speaker_microphone_settings.png){class="glboxshadow"}

Det beror på att högtalaren och mikrofonen, på grund av webbläsarens säkerhetspolicyer, som standard inaktiveras respektive stängs av varje gång du startar om, loggar in på KVM-enheten igen eller uppdaterar webbsidan (vid lokal åtkomst). Du kan aktivera dem manuellt vid behov.

Första gången du aktiverar mikrofonen krävs ett godkännande, enligt bilden nedan.

![Webbläsare](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/google-browser.jpg){class="glboxshadow"}
