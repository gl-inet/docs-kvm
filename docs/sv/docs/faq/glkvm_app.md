# GLKVM-appen {#glkvm-app}

![Ikon för GLKVM-appen](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

GLKVM-appen är ett program för Windows och macOS som är utformat för fjärråtkomst till och fjärrstyrning av enheter som är anslutna till en GL.iNet KVM. Den passar utmärkt för IT-proffs, distansarbetare och avancerade användare som behöver direkt åtkomst till datorer på annan plats.

Användare av macOS kan ladda ned den [här](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"}.

Användare av Windows kan ladda ned den [här](https://www.gl-inet.com/app-rm/){target="_blank"} (endast för Windows 10 och senare).

Användare av Android kan ladda ned den [här](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"}.

Användare av iOS kan ladda ned den från [App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"}.

Du kan också använda molntjänsten för fjärråtkomst via en webbläsare. Klicka [här](remote_access_via_cloud.md) för mer information.
