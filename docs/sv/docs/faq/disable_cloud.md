# Så inaktiverar du molntjänsten {#how-to-disable-cloud-service}

GL.iNet KVM Cloud är aktiverad som standard, så att användare kan koppla KVM-enheter till sitt molnkonto för fjärråtkomst.

Om du inte vill använda molntjänsten kan du inaktivera den manuellt. När den är inaktiverad går det inte längre att få fjärråtkomst via molntjänsten och GLKVM-appen. För att aktivera den igen måste du logga in på din KVM lokalt via domännamn eller IP-adress, eller på distans via Tailscale.

Följ stegen nedan om du behöver inaktivera molntjänsten.

1. Logga in på KVM-enheten och gå till **Cloud Service** i det övre högra hörnet. Klicka på kugghjulsikonen och klicka på **Disable**.

    ![Inaktivera molnet](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_1.png){class="glboxshadow" width="400"}

2. När tjänsten har inaktiverats visas sidan enligt nedan.

    ![Inaktivera molnet](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_2.png){class="glboxshadow"}
