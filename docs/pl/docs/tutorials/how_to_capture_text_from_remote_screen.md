# Jak przechwycić tekst ze zdalnego ekranu {#how-to-capture-text-from-the-remote-screen}

Funkcja rozpoznawania tekstu pozwala zaznaczyć obszar na zdalnym ekranie i łatwo wyodrębnić z niego tekst. Wykorzystuje technologię optycznego rozpoznawania znaków (OCR) i jest dostępna od wersji firmware v1.9.0.

Dzięki tej funkcji możesz przechwycić tekst ze zdalnego ekranu, czyli ze sterowanego urządzenia, i skopiować go na urządzenie sterujące.

Aby przechwycić tekst ze zdalnego ekranu, wykonaj poniższe kroki.

## Firmware v1.10 i nowszy {#firmware-v110-and-above}

1. Zaloguj się do konsoli KVM i przejdź do **Toolbox** -> **OCR**. Kliknij strzałkę w dół, aby wybrać język rozpoznawania: chiński, angielski lub tryb dwujęzyczny (Zh/En).

    ![Wybór języka OCR](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_1.png){class="glboxshadow"}

2. Kliknij **Capture**. Zdalny ekran zostanie przyciemniony. Aby zakończyć przechwytywanie tekstu, kliknij **Cancel**.

    ![Rozpoczęcie przechwytywania](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_2.png){class="glboxshadow"}

3. Zaznacz prostokątny obszar wokół tekstu do wyodrębnienia, jak pokazano poniżej.

    ![Zaznaczanie obszaru](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_3.png){class="glboxshadow"}

4. System automatycznie rozpozna tekst w zaznaczonym obszarze. Możesz go następnie skopiować.

    ![Rozpoznany tekst](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_4.png){class="glboxshadow"}

## Firmware v1.9.x {#firmware-v19x}

1. Zaloguj się do konsoli KVM. Kliknij strzałkę w dół, aby wybrać język rozpoznawania: chiński, angielski lub tryb dwujęzyczny (Zh/En).

    ![Wybór języka rozpoznawania](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/1.png){class="glboxshadow"}

2. Kliknij ikonę **„T”** pośrodku górnego paska narzędzi. Zdalny ekran zostanie przyciemniony.

    ![Ikona rozpoznawania tekstu](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/2.png){class="glboxshadow"}

3. Zaznacz prostokątny obszar wokół tekstu do wyodrębnienia, jak pokazano poniżej.

    ![Zaznaczanie tekstu](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/3.png){class="glboxshadow"}

4. System automatycznie rozpozna tekst w zaznaczonym obszarze. Możesz go następnie skopiować.

    ![Wynik rozpoznawania](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/4.png){class="glboxshadow"}
