# Jak ustawić statyczny adres IP dla KVM {#how-to-set-a-static-ip-for-kvm}

Ten poradnik przedstawia kroki ustawiania statycznego adresu IP GL.iNet KVM bezpośrednio w konsoli, gdy nadrzędny router nie może go przydzielić.

Wybierz instrukcję odpowiednią dla swojej wersji firmware.

## Firmware v1.9 i starszy {#firmware-v19-and-earlier}

W poniższym przykładzie użyto Comet (GL-RM1).

1. Zaloguj się do konsoli Comet i przejdź do **Settings** -> **Network**. Kliknij adres IP lub ikonę strzałki w prawo.

    ![Ustawienia sieci](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/settings-network.png){class="glboxshadow"}

2. Przełącz na **Static**. Wpisz adres IP z odpowiedniej podsieci, maskę sieci, bramę i serwery DNS dla Comet, a następnie kliknij **Confirm**.

    ![Statyczne ustawienia Ethernet](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet-settings-static.png){class="glboxshadow"}

## Firmware v1.10 i nowszy {#firmware-v110-and-above}

W poniższym przykładzie użyto Comet Pro (GL-RM10).

1. Zaloguj się do konsoli Comet Pro i kliknij ikonę ustawień na pasku nawigacji, aby otworzyć stronę ustawień.

    ![Ustawienia sieci](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/setting_network.png){class="glboxshadow"}

2. Przejdź do **Network** i kliknij przycisk **Static** w ustawieniach Ethernet. Wpisz adres IP z odpowiedniej podsieci, maskę sieci, bramę i serwery DNS dla Comet Pro, a następnie kliknij **Confirm**.

    ![Konfiguracja statycznego adresu IP](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet_settings_static.png){class="glboxshadow"}
