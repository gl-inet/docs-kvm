# Jak wyeksportować logi urządzenia i aplikacji

Ten poradnik wyjaśnia, jak wyeksportować logi urządzenia KVM i aplikacji GLKVM na potrzeby rozwiązywania problemów.

## Logi urządzenia

Zaloguj się do konsoli KVM, kliknij **Help** i wybierz **Export Log Files**.

![Logi urządzenia](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/device_log.png){class="glboxshadow"}

## Logi aplikacji

Logi aplikacji można eksportować z aplikacji komputerowej i mobilnej.

W aplikacji komputerowej zaloguj się do GLKVM, kliknij ikonę znaku zapytania w prawym górnym rogu i wybierz **Export Log**.

![Logi aplikacji komputerowej](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/web_app_log.png){class="glboxshadow"}

W aplikacji mobilnej zaloguj się do GLKVM, przejdź do **Settings** -> **Help Center** i kliknij **Export Logs**.

![Logi aplikacji mobilnej](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/ios_app_log.png){class="glboxshadow"}
