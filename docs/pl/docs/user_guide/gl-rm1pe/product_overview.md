## Dioda LED {#led}

Na górnym panelu Comet PoE znajduje się jedna dioda LED.

| Stan diody LED | Opis |
| :----------------------- | :-------------------------------- |
| Świeci na niebiesko | Uruchamianie |
| Miga na biało | Urządzenie uruchomione, brak połączenia z Internetem |
| Świeci na biało | Połączono z Internetem |
| Miga na niebiesko i biało | Aktualizacja oprogramowania układowego |
