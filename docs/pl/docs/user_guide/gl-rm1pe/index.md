# Comet PoE (GL-RM1PE) — podręcznik użytkownika {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) to wersja urządzenia [Comet (GL-RM1)](../gl-rm1/index.md) z zasilaniem Power-over-Ethernet, zaprojektowana z myślą o prostej instalacji za pomocą jednego kabla. Model PoE pobiera zasilanie i łączy się z siecią przez ten sam kabel Ethernet, ograniczając liczbę przewodów i upraszczając montaż, zwłaszcza w trudno dostępnych miejscach.

Ponadto w tej wersji pojemność pamięci EMMC zwiększono do 32GB, co ułatwia przechowywanie dzienników systemowych, nagrań lub niestandardowego oprogramowania układowego.
