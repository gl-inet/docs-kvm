# Comet (GL-RM1) V1/V2 — podręcznik użytkownika {#comet-gl-rm1-v1v2-user-guide}

Comet (GL-RM1) V1/V2 to zdalne urządzenie KVM o szerokim zakresie zastosowań. Umożliwia zdalne sterowanie domowym komputerem poza domem i dostęp do lokalnych zasobów. Obsługuje zdalne sterowanie urządzeniami bez dostępu do sieci, dzięki czemu można rozwiązywać problemy z uruchamianiem komputera i zmieniać ustawienia BIOS-u. Funkcja zdalnego przesyłania plików ułatwia wymianę danych z komputerami zarówno podłączonymi do sieci, jak i bez takiego połączenia. Obsługa dźwięku wzbogaca zdalną pracę. Jest to przydatne narzędzie do pracy zdalnej i zarządzania urządzeniami.
