# Comet Pro (GL-RM10) — podręcznik użytkownika {#comet-pro-gl-rm10-user-guide}

Comet Pro (GL-RM10) to rozwiązanie do zdalnego dostępu KVM przez Wi-Fi. Czterordzeniowy procesor A53, 1GB pamięci DDR3 i 32GB pamięci eMMC zapewniają płynną pracę. Ekran dotykowy pozwala szybko sprawdzić adres IP urządzenia i wykonywać podstawowe czynności, takie jak konfiguracja Wi-Fi.

Urządzenie obsługuje dwuzakresowe Wi-Fi 6 zapewniające stabilne i szybkie połączenie oraz przekazywanie obrazu bez utraty jakości. Wyjście wideo 4K@30FPS zapewnia szczegółowy obraz podczas zdalnego sterowania. Comet Pro sprawdza się w wydajnym zdalnym zarządzaniu urządzeniami zarówno w zastosowaniach prywatnych, jak i zawodowych.
