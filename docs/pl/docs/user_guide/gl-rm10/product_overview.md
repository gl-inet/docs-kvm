## Ekran dotykowy {#touchscreen}

| Widok ekranu | Opis |
| :-------------------------------- | :------------------ |
| ![Uruchamianie](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **Uruchamianie**<br>Włącz Comet Pro. Pojawi się logo GL.iNet, a następnie pasek postępu uruchamiania. Gdy pasek wypełni się do końca, urządzenie jest gotowe. |
| ![Hasło ekranu](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **Ustawianie hasła ekranu**<br>Ustaw hasło ekranu urządzenia Comet Pro, aby chronić swoją prywatność. |
| ![Konfiguracja sieci](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **Konfiguracja sieci**<br>Połącz Comet Pro z siecią Wi-Fi 2.4GHz/5GHz lub podłącz je kablem Ethernet do urządzenia sieciowego (np. routera, przełącznika sieciowego lub gniazda Ethernet). |
| ![Ekran główny](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **Ekran główny**<br>**Lewy górny róg**: stan chmury i sieci.<br>**Prawy górny róg**: czas systemowy.<br>**Środek**: adres IP urządzenia (widoczny tylko przy połączeniu z Internetem).<br>**Dół**: sygnały klawiatury i myszy, sygnał HDMI oraz stan połączenia USB. |
| ![Ustawienia podstawowe](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **Ustawienia podstawowe**<br>Na ekranie głównym przesuń palcem od prawej do lewej, aby otworzyć ustawienia podstawowe, w tym **Screen Display**, **Wi-Fi** i **Cloud Service**. |
| ![Działania systemowe](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **Menu systemowe**<br>Na ekranie głównym przesuń palcem od góry w dół, aby otworzyć menu systemowe z opcjami **Reboot** i **Lock Screen**. |
| ![Godzina](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **Ekran blokady**<br>Ekran blokady wyświetla godzinę i datę. |
| ![Przywracanie ustawień fabrycznych](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Przywracanie ustawień fabrycznych**<br>Przy włączonym KVM włóż szpilkę w otwór resetowania i przytrzymaj przez 8 sekund, aby przywrócić ustawienia fabryczne. Zwolnienie przed upływem 8 sekund anuluje resetowanie. |

## Zawartość opakowania {#package-contents}

- 1 x Comet Pro (GL-RM10)
- 1 x instrukcja obsługi
- 1 x karta z podziękowaniem
- 1 x kabel Ethernet
- 2 x kabel HD
- 1 x kabel USB (Type-A na Type-C)
- 1 x kabel USB (Type-C na Type-C)
- 1 x zasilacz USB-A
- 1 x adapter (zależnie od kraju dostawy)
