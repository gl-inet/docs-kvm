# Comet X (GL-RM4PE) — podręcznik użytkownika {#comet-x-gl-rm4pe-user-guide}

Comet X to czteroportowy zdalny KVM z obsługą PoE, do którego można podłączyć do 4 serwerów w szafie rack. Po konfiguracji możesz sterować podłączonymi urządzeniami z dowolnego miejsca przez przeglądarkę lub aplikację, uzyskując płynny obraz 4K@30fps bez dodatkowego oprogramowania. Wbudowany ekran dotykowy o przekątnej 3.69 cala pozwala szybko sprawdzić adresy IP, stan połączenia i aktywne sesje. Zasilanie PoE upraszcza wdrożenie i ogranicza liczbę kabli w środowisku serwerowym. Pamięć eMMC o pojemności 64GB służy także jako wbudowane repozytorium plików ISO, ułatwiając instalację systemów operacyjnych i odzyskiwanie awaryjne.
