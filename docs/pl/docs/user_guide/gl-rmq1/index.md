# Comet Q (GL-RMQ1) — podręcznik użytkownika {#comet-q-gl-rmq1-user-guide}

Comet Q to urządzenie mieszczące się w dłoni, które łączy się przez USB-C ze zgodnymi telefonami komórkowymi, komputerami Mac mini i laptopami (wymagana obsługa DP Alt Mode). Po podłączeniu wystarczy otworzyć przeglądarkę, aby uzyskać pełną kontrolę nad urządzeniem docelowym bez instalowania dodatkowego oprogramowania ani skomplikowanej konfiguracji. Wbudowany ekran dotykowy o przekątnej 1.8 cala umożliwia szybką konfigurację, sprawdzanie stanu i wywoływanie działań bezpośrednio na urządzeniu.

To pierwszy na świecie KVM obsługujący iPhone'y, który pozwala odblokowywać, dotykać, przesuwać i w pełni obsługiwać urządzenie z iOS z komputera z Windows — funkcja ta wcześniej nie była dostępna.
