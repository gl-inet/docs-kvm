# Comet 5G (GL-RM10RC) — podręcznik użytkownika {#comet-5g-gl-rm10rc-user-guide}

Comet 5G (GL-RM10RC) to zdalne urządzenie KVM z obsługą 5G RedCap i wbudowaną łącznością komórkową, zapewniające pełną kontrolę nad urządzeniami nawet w miejscach bez sieci przewodowej. Zwiększa to elastyczność wdrożeń. Obsługa 5G RedCap, Wi-Fi 6 oraz przełączania awaryjnego połączeń Ethernet pozwala utrzymać łączność w różnych warunkach sieciowych.

Wbudowany ekran dotykowy upraszcza konfigurację i codzienną obsługę, oferując prosty i wydajny interfejs zdalnego zarządzania. W połączeniu z akcesoriami, takimi jak płytka ATX lub Fingerbot, umożliwia zdalne włączanie i wyłączanie podłączonego sprzętu, sprawdzając się w zarządzaniu rozproszonymi urządzeniami i serwisie terenowym.
