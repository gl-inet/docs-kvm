# Jak zaktualizować oprogramowanie sprzętowe KVM {#how-to-upgrade-your-kvms-firmware}

Aktualizacje oprogramowania sprzętowego wprowadzają nowe funkcje i poprawiają stabilność urządzenia. Wykonaj poniższe czynności, aby przeprowadzić aktualizację.

1. Zaloguj się do konsoli KVM i kliknij wersję oprogramowania sprzętowego w prawym górnym rogu, aby sprawdzić dostępność aktualizacji.

    ![Aktualizacja](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. Jeśli w wyświetlonym oknie dostępna jest nowsza wersja oprogramowania, możesz przeprowadzić **aktualizację online**. W przeciwnym razie oprogramowanie KVM jest aktualne.

    ![Oprogramowanie jest aktualne](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. Kliknij **Update Settings**, aby przeprowadzić aktualizację lokalną, dołączyć do programu beta lub zachować bieżącą konfigurację.

    ![Ustawienia aktualizacji](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade**: Przed aktualizacją lokalną pobierz najnowsze oprogramowanie sprzętowe z [centrum pobierania oprogramowania](https://dl.gl-inet.com/kvm){target="_blank"}.

    - **Join Beta Program**: Oprogramowanie beta zapewnia wcześniejszy dostęp do nowych funkcji. Wersje beta mogą być niestabilne i wpływać na działanie urządzenia. Dołącz tylko wtedy, gdy akceptujesz testowanie oprogramowania przedpremierowego.

    - **Save current configuration**: Ta opcja zachowuje powiązanie z kontem usługi chmurowej.
