# Który plan usługi KVM Cloud wybrać {#which-kvm-cloud-service-plan-is-right-for-you}

Usługa KVM Cloud jest dostępna w dwóch planach: bezpłatnym Standard i płatnym Advanced. Screen Wall i Device Sharing to funkcje premium dostępne tylko w planie Advanced. Poniższa tabela porównuje funkcje obu planów. W razie potrzeby możesz przejść na plan Advanced.

## Porównanie korzyści {#benefits-comparison}
| Główna funkcja | Standard | Advanced |
| ---- | ---- | ---- |
| Połączenie podstawowe | ✓ Dożywotnie połączenie podstawowe | ✓ Dożywotnie połączenie podstawowe |
| Powiązane urządzenia | ✓ Nieograniczona liczba urządzeń na koncie | ✓ Nieograniczona liczba urządzeń na koncie |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">Brak obsługi</span> | ✓ Możliwość dodania do **9** pozycji |
| Device Sharing | <span style="color:red;">✗</span> <span style="color:#888;">Brak obsługi</span> | ✓ Udostępnianie maksymalnie **5** użytkownikom |
| Kanały dostępu zdalnego | ✓ Jeden aktywny kanał na urządzenie | ✓ Wiele jednoczesnych kanałów na urządzenie |
| Dostęp do podłączonych urządzeń | ✓ Nieograniczona liczba urządzeń | ✓ Nieograniczona liczba urządzeń |

**Uwaga**: Kanały dostępu zdalnego dotyczą usługi GLKVM Cloud i aplikacji GLKVM.
