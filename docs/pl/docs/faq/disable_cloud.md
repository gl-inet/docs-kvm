# Jak wyłączyć usługę chmurową {#how-to-disable-cloud-service}

Usługa chmurowa GL.iNet KVM jest domyślnie włączona i umożliwia powiązanie urządzeń KVM z kontem w chmurze w celu uzyskania dostępu zdalnego.

Jeśli nie chcesz korzystać z usługi chmurowej, możesz wyłączyć ją ręcznie. Po jej wyłączeniu dostęp zdalny przez usługę chmurową i aplikację GLKVM będzie niedostępny. Aby włączyć ją ponownie, zaloguj się do KVM lokalnie za pomocą nazwy domeny lub adresu IP albo zdalnie przez Tailscale.

Aby wyłączyć usługę chmurową, wykonaj poniższe czynności.

1. Zaloguj się do urządzenia KVM i przejdź do **Cloud Service** w prawym górnym rogu. Kliknij ikonę koła zębatego, a następnie **Disable**.

    ![Wyłączanie usługi chmurowej](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_1.png){class="glboxshadow" width="400"}

2. Po wyłączeniu usługi strona będzie wyglądać jak poniżej.

    ![Wyłączanie usługi chmurowej](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_2.png){class="glboxshadow"}
