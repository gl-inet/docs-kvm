# Co zrobić, jeśli aplikacja GLKVM nie znajduje urządzenia {#what-should-i-do-if-no-device-is-found-in-the-glkvm-app}

Podczas pierwszego dodawania urządzenia KVM po wybraniu **Auto Discover** aplikacja GLKVM może wyświetlić komunikat **No device found**.

![Nie znaleziono urządzenia](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

Skorzystaj z poniższych wskazówek:

1. Upewnij się, że wszystkie przewody są prawidłowo podłączone do urządzenia KVM, w tym przewód zasilający Type-C, przewód HDMI, przewód Ethernet (jeśli jest wymagany) i przewód USB-A.

2. Upewnij się, że KVM ma połączenie z Internetem. Ciągłe białe światło diody LED oznacza prawidłowe połączenie sieciowe.

3. Upewnij się, że KVM i urządzenie sterujące są podłączone do tej samej sieci.
