# Aplikacja GLKVM {#glkvm-app}

![Ikona aplikacji GLKVM](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

Aplikacja GLKVM dla systemów Windows i macOS służy do zdalnego dostępu do urządzeń podłączonych do KVM GL.iNet i sterowania nimi. Jest przeznaczona dla specjalistów IT, osób pracujących zdalnie i zaawansowanych użytkowników potrzebujących bezpośredniego dostępu do odległych komputerów.

Wersję dla macOS można pobrać [tutaj](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"}.

Wersję dla Windows można pobrać [tutaj](https://www.gl-inet.com/app-rm/){target="_blank"} (tylko dla Windows 10 i nowszych).

Wersję dla Androida można pobrać [tutaj](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"}.

Wersję dla iOS można pobrać z [App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"}.

Możesz też korzystać z usługi chmurowej, aby uzyskać dostęp zdalny przez przeglądarkę. Szczegóły znajdziesz [tutaj](remote_access_via_cloud.md).
