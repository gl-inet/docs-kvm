# Dlaczego ustawienia głośnika i mikrofonu nie są zachowywane {#why-cant-i-keep-my-speaker-and-microphone-settings}

Po włączeniu Speaker lub Microphone w konsoli KVM (w Settings -> Remote Device Settings) możesz zauważyć, że ustawienia te nie są zachowywane po ponownym uruchomieniu, ponownym zalogowaniu do KVM lub odświeżeniu strony podczas dostępu lokalnego.

Speaker zostanie automatycznie wyłączony, a Microphone, choć po restarcie lub odświeżeniu strony nadal może być oznaczony jako włączony, będzie wyciszony.

![Ustawienia głośnika i mikrofonu](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/speaker_microphone_settings.png){class="glboxshadow"}

Wynika to z zasad bezpieczeństwa przeglądarki: Speaker i Microphone są domyślnie wyłączane lub wyciszane przy każdym restarcie, ponownym logowaniu do KVM lub odświeżeniu strony podczas dostępu lokalnego. W razie potrzeby możesz włączyć je ręcznie.

Przy pierwszym włączeniu Microphone wymagane jest udzielenie uprawnienia, jak pokazano poniżej.

![Uprawnienia w przeglądarce](https://static.gl-inet.com/docs/kvm/faq/speaker_microphone_settings_cannot_be_retained/google-browser.jpg){class="glboxshadow"}
