# Come dissociare il dispositivo KVM dal cloud {#how-to-unbind-my-kvm-device-from-the-cloud}

Puoi dissociare i dispositivi KVM dal cloud in tre modi: tramite accesso locale, tramite l'app GLKVM o tramite il cloud.

## Dissociare tramite accesso locale {#unbind-via-local-access}

1. Assicurati che il computer si trovi sulla stessa rete locale del dispositivo KVM.

2. Apri un browser web sul computer; per una migliore compatibilità, è consigliato Chrome o Edge. Digita `glkvm.local` o l'indirizzo IP del KVM nella barra degli indirizzi per aprire la pagina di accesso locale di GLKVM. Inserisci la password di amministratore per accedere.

3. Dopo l'accesso, vai su **Cloud Service** nell'angolo in alto a destra, fai clic sull'icona a forma di ingranaggio e seleziona **Unbind**.

    ![unbind via local](https://static.gl-inet.com/docs/kvm/faq/unbind/local_unbind.png){class="glboxshadow"}

## Dissociare tramite l'app GLKVM {#unbind-via-glkvm-app}

1. Accedi all'app GLKVM e fai clic su **Manage** nell'angolo in alto a destra del dispositivo.

    ![unbind via app](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_1.png){class="glboxshadow"}

2. Fai clic su **More** e seleziona **Unbind**.

    ![app unbinding](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_2.png){class="glboxshadow"}

## Dissociare tramite il cloud {#unbind-via-the-cloud}

1. Apri un browser web sul computer; per una migliore compatibilità, è consigliato Chrome o Edge. Digita `glkvm.com` nella barra degli indirizzi e accedi con il tuo account cloud.

2. Dopo l'accesso, fai clic sull'icona con i tre puntini nell'angolo in basso a destra del dispositivo e seleziona **Device Detail**.

    ![unbind via cloud](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_1.png){class="glboxshadow"}

3. Nella pagina dei dettagli, fai clic su **Unbind**.

    ![unbind via cloud](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_2.png){class="glboxshadow gl-80-desktop"}
