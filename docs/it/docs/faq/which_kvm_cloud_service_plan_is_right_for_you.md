# Quale piano del servizio cloud KVM scegliere {#which-kvm-cloud-service-plan-is-right-for-you}

Il servizio cloud KVM è disponibile in due piani: Standard, gratuito, e Advanced, a pagamento. Screen Wall e Device Sharing sono funzioni premium disponibili solo nel piano Advanced. La tabella seguente confronta le funzioni dei due piani. Puoi passare al piano Advanced in base alle tue esigenze.

## Confronto delle funzionalità {#benefits-comparison}
| Funzione principale | Standard | Advanced |
| ---- | ---- | ---- |
| Connessione di base | ✓ Connessione di base a vita | ✓ Connessione di base a vita |
| Dispositivi associati | ✓ Numero illimitato di dispositivi nell'account | ✓ Numero illimitato di dispositivi nell'account |
| Screen Wall | <span style="color:red;">✗</span> <span style="color:#888;">Non supportata</span> | ✓ Fino a **9** dispositivi aggiunti |
| Device Sharing | <span style="color:red;">✗</span> <span style="color:#888;">Non supportata</span> | ✓ Condivisione con un massimo di **5** utenti |
| Canali di accesso remoto | ✓ Un canale attivo per dispositivo | ✓ Più canali simultanei per dispositivo |
| Accesso ai dispositivi collegati | ✓ Dispositivi illimitati | ✓ Dispositivi illimitati |

**Nota**: i canali di accesso remoto si applicano a GLKVM Cloud e alle app.
