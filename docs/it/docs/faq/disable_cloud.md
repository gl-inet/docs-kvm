# Come disattivare il servizio cloud {#how-to-disable-cloud-service}

Il servizio cloud del KVM GL.iNet è attivo per impostazione predefinita e consente di associare i dispositivi KVM al proprio account cloud per l'accesso remoto.

Se non vuoi usare il servizio cloud, puoi disattivarlo manualmente. Una volta disattivato, l'accesso remoto tramite il servizio cloud e l'app GLKVM non sarà disponibile. Per riattivarlo, dovrai accedere al KVM localmente tramite nome di dominio o indirizzo IP, oppure da remoto tramite Tailscale.

Se necessario, segui i passaggi indicati di seguito per disattivare il servizio cloud.

1. Accedi al dispositivo KVM e vai su **Cloud Service** nell'angolo in alto a destra. Fai clic sull'icona a forma di ingranaggio, quindi su **Disable**.

    ![disable cloud](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_1.png){class="glboxshadow" width="400"}

2. Una volta disattivato il servizio, la pagina apparirà come nell'immagine seguente.

    ![disable cloud](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_2.png){class="glboxshadow"}
