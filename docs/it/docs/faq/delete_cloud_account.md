# Come eliminare l'account cloud {#how-to-delete-my-cloud-account}

Per motivi di sicurezza, puoi eliminare il tuo account cloud se non lo utilizzi più.

**AVVERTENZA**:

1. I router e i dispositivi KVM GL.iNet condividono un servizio cloud unificato. Se elimini l'account cloud, la modifica si applicherà sia ai router sia ai dispositivi KVM.
2. L'eliminazione cancellerà definitivamente tutti i servizi associati, i dati e le informazioni personali, senza possibilità di recupero.
3. Esci da tutte le organizzazioni prima di procedere con l'eliminazione.

---

Puoi eliminare il tuo account cloud in due modi: tramite l'app GLKVM o tramite il cloud.

Se necessario, segui i passaggi indicati di seguito per eliminare l'account cloud.

## Eliminazione nell'app GLKVM {#delete-in-glkvm-app}

1. Accedi all'app GLKVM, fai clic sul tuo profilo nell'angolo in alto a sinistra e seleziona **Settings**.

    ![app delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete1.png){class="glboxshadow"}

2. Nelle impostazioni **Account**, fai clic sul pulsante **Delete**. Tutti i dati verranno cancellati. Procedi con cautela.

    ![app delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete2.png){class="glboxshadow"}

## Eliminazione nel cloud {#delete-in-the-cloud}

1. Apri un browser web sul computer; per una migliore compatibilità, è consigliato Chrome o Edge. Digita `glkvm.com` nella barra degli indirizzi e accedi con il tuo account cloud.

2. Dopo l'accesso, fai clic sul tuo profilo nell'angolo in alto a destra e seleziona **Personal Center**.

    ![cloud delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete1.png){class="glboxshadow"}

3. Scorri fino in fondo alla pagina e fai clic sul pulsante **Delete**. Tutti i dati verranno cancellati. Procedi con cautela.

    ![cloud delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete2.png){class="glboxshadow"}
