# Come impostare un IP statico per il KVM

Questo tutorial spiega come impostare un IP statico per il tuo KVM GL.iNet direttamente dalla console quando il router a monte non riesce ad assegnarne uno.

Segui i passaggi appropriati per la tua versione del firmware.

## Firmware v1.9 e versioni precedenti

I passaggi seguenti utilizzano Comet (GL-RM1) come esempio.

1. Accedi alla console di Comet e vai su **Settings** -> **Network**. Fai clic sull'indirizzo IP o sull'icona della freccia a destra.

    ![Impostazioni di rete](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/settings-network.png){class="glboxshadow"}

2. Passa a **Static**. Inserisci un indirizzo IP all'interno della sottorete, insieme alla maschera di rete, al gateway e ai server DNS di Comet, quindi fai clic su **Confirm**.

    ![Impostazioni Ethernet statiche](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet-settings-static.png){class="glboxshadow"}

## Firmware v1.10 e versioni successive

I passaggi seguenti utilizzano Comet Pro (GL-RM10) come esempio.

1. Accedi alla console di Comet Pro e fai clic sull'icona Settings nella barra di navigazione per aprire la pagina delle impostazioni.

    ![Impostazioni di rete](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/setting_network.png){class="glboxshadow"}

2. Vai su **Network** e fai clic sul pulsante **Static** in Ethernet Settings. Inserisci un indirizzo IP all'interno della sottorete, insieme alla maschera di rete, al gateway e ai server DNS di Comet Pro, quindi fai clic su **Confirm**.

    ![Impostazioni Ethernet statiche](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet_settings_static.png){class="glboxshadow"}
