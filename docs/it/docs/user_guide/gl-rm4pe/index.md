# Guida utente di Comet X (GL-RM4PE) {#comet-x-gl-rm4pe-user-guide}

Comet X è un KVM remoto a quattro porte con supporto PoE che può collegarsi a un massimo di 4 server nel rack. Dopo la configurazione, permette di controllare tutti i dispositivi collegati da qualsiasi luogo tramite browser o app, con video fluido a 4K@30fps e senza software aggiuntivo. Il touchscreen integrato da 3.69 pollici consente di verificare subito indirizzi IP, stato online e sessioni attive. L'alimentazione PoE semplifica l'installazione e riduce l'ingombro dei cavi nell'ambiente server. La memoria eMMC da 64GB funge anche da archivio integrato per i file ISO, semplificando l'installazione dei sistemi operativi e il ripristino di emergenza.
