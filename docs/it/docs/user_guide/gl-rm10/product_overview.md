## Touchscreen { #touchscreen }

| Visualizzazione sullo schermo | Descrizione |
| :-------------------------------- | :------------------ |
| ![booting](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **Avvio**<br>Accendere Comet Pro. Compariranno il logo GL.iNet e una barra di avanzamento. Quando la barra è completa, il dispositivo ha terminato l'avvio. |
| ![screen password](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **Impostazione della password dello schermo**<br>Impostare una password per lo schermo di Comet Pro per proteggere la propria privacy. |
| ![setup network](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **Configurazione della rete**<br>Collegare Comet Pro a una rete Wi-Fi a 2.4GHz/5GHz oppure a un dispositivo di rete, come un router, uno switch o una presa Ethernet, tramite un cavo Ethernet. |
| ![home](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **Schermata iniziale**<br>**In alto a sinistra**: stato del cloud e della rete.<br>**In alto a destra**: ora di sistema.<br>**Al centro**: indirizzo IP del dispositivo (visibile solo quando è connesso a Internet).<br>**In basso**: segnale di tastiera e mouse, segnale HDMI e stato della connessione USB. |
| ![basic settings](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **Impostazioni di base**<br>Nella schermata iniziale, scorrere da destra verso sinistra per accedere alle impostazioni di base, tra cui **Screen Display**, **Wi-Fi** e **Cloud Service**. |
| ![system actions](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **Menu di sistema**<br>Nella schermata iniziale, scorrere dall'alto verso il basso per accedere al menu di sistema, che include **Reboot** e **Lock Screen**. |
| ![time](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **Schermata di blocco**<br>La schermata di blocco mostra l'ora e la data. |
| ![reset](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Ripristino delle impostazioni di fabbrica**<br>Con il KVM acceso, inserire uno spillo nel foro di ripristino e tenerlo premuto per 8 secondi per ripristinare le impostazioni di fabbrica. Rilasciarlo prima che trascorrano 8 secondi per annullare il ripristino. |

## Contenuto della confezione { #package-contents }

- 1 x Comet Pro (GL-RM10)
- 1 x Manuale utente
- 1 x Biglietto di ringraziamento
- 1 x Cavo Ethernet
- 2 x Cavo HD
- 1 x Cavo USB (Type-A a Type-C)
- 1 x Cavo USB (Type-C a Type-C)
- 1 x Alimentatore USB-A
- 1 x Adattatore (in base al Paese di consegna)
