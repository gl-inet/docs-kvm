# Guida utente di Comet Q (GL-RMQ1)

Comet Q è un dispositivo grande quanto il palmo di una mano che si collega tramite USB-C a telefoni compatibili, computer Mac mini e portatili (è richiesto il supporto DP Alt Mode). Dopo il collegamento, è sufficiente aprire un browser per controllare completamente il dispositivo, senza installare software aggiuntivo o eseguire configurazioni complesse. Il touchscreen integrato da 1.8 pollici consente di configurare rapidamente il dispositivo, verificarne lo stato ed eseguire azioni direttamente dall'unità.

È il primo KVM al mondo a supportare gli iPhone e permette di sbloccare, toccare, scorrere e usare completamente un dispositivo iOS da un PC Windows, una funzionalità prima non disponibile.
