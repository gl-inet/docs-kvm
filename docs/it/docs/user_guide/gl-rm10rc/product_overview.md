## Caratteristiche principali { #highlights }

1. **5G RedCap**

    Comet 5G integra la tecnologia 5G RedCap per offrire un accesso Internet flessibile e permettere installazioni indipendenti dalle reti fisse presenti sul posto.

2. **Failover di rete**

    Grazie alla connettività cellulare integrata, al Wi-Fi 6 e al supporto del failover Ethernet, Comet 5G assicura la continuità operativa. Se una connessione si interrompe, passa automaticamente alla rete successiva disponibile, consentendo l'uso ininterrotto del KVM remoto anche in condizioni difficili.

3. **Wi-Fi 6 dual-band**

    Comet 5G supporta Wi-Fi 6 dual-band (2.4GHz e 5GHz), offrendo una connettività wireless veloce, stabile e a bassa latenza per il controllo remoto e l'accesso ai dati.

4. **Controllo nelle vicinanze tramite modalità AP**

    Comet 5G offre il controllo Wi-Fi nelle vicinanze, che permette una rapida gestione locale senza cavi. Impostare la modalità di rete Wi-Fi di Comet 5G su AP per generare un SSID Wi-Fi univoco. Collegarsi a questo SSID per accedere in sicurezza alla console di Comet 5G.

    **Nota**: Attivando la modalità AP, Comet 5G si disconnette dal Wi-Fi a monte e offre solo l'accesso nelle vicinanze, senza connettività Internet.

5. **Accesso remoto tramite browser**

    Comet 5G consente di accedere alla console direttamente dal browser, senza installare un client. L'accesso usa la crittografia HTTPS ed evita gli avvisi dei certificati autofirmati, offrendo una connessione sicura e semplice senza software aggiuntivo.

6. **Design curato e touchscreen**

    Comet 5G presenta una scocca grigio scuro con linee morbide, angoli arrotondati e una finitura opaca testurizzata che unisce resistenza e qualità al tatto. Il touchscreen TFT da 3.69 pollici offre un'interfaccia intuitiva per accedere rapidamente alle funzioni del dispositivo.

7. **Video 4K e audio bidirezionale**

    Comet 5G supporta un'uscita video fino a 4K@30FPS con passthrough HDMI, consentendo la visualizzazione locale e l'accesso remoto simultanei senza uno splitter esterno. L'audio bidirezionale permette una comunicazione chiara nelle videoconferenze o durante l'assistenza tecnica remota.

8. **Installazione su server proprio**

    Comet 5G consente un'installazione flessibile su server proprio con sistemi operativi diffusi, tra cui Linux e Ubuntu, offrendo pieno controllo sull'accesso remoto e sulla riservatezza dei dati. Il sistema richiede un server cloud con almeno una CPU dual-core e 2GB di memoria, per garantire riservatezza e funzionamento affidabile.

9. **Controllo remoto dell'alimentazione**

    Comet 5G dispone di una porta USB per collegare accessori esterni come una scheda ATX o Fingerbot e controllare da remoto l'alimentazione delle apparecchiature collegate.

    **Nota**: Gli accessori opzionali sono venduti separatamente.

## Bande di frequenza { #frequency-bands }

Comet 5G supporta le seguenti bande di frequenza.

- **5G NR**

    3GPP Release 17 RedCap, funzionamento SA (Sub-6 GHz) n1 / n2 / n3 / n5 / n7 / n8 / n12 / n13 / n14 / n18 / n20 / n25 / n26 / n28 / n30 / n38 / n40 / n41 / n48 / n66 / n70 / n77 / n78 / n79

- **LTE FDD**

    B1 / B2 / B3 / B4 / B5 / B7 / B8 / B12 / B13 / B14 / B17 / B18 / B19 / B20 / B25 / B26 / B28 / B30 / B66 / B70

- **LTE TDD**

    B34 / B38 / B39 / B40 / B41 / B42 / B43 / B48
