# Guida utente di Comet (GL-RM1) V1/V2 {#comet-gl-rm1-v1v2-user-guide}

Comet (GL-RM1) V1/V2 è un dispositivo KVM remoto adatto a numerose applicazioni. Consente di controllare il computer di casa quando si è fuori, accedere alle risorse locali e molto altro. Supporta il controllo remoto di dispositivi offline, permettendo di gestire problemi di avvio del computer e modificare le impostazioni del BIOS. La funzione di trasferimento remoto dei file semplifica lo scambio di dati con computer sia online sia offline. Il supporto audio rende l'interazione remota più completa. È uno strumento essenziale per il lavoro da remoto e la gestione dei dispositivi.
