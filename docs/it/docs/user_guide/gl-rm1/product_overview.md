## LED

Sul pannello superiore di Comet è presente un indicatore LED.

| Stato del LED | Descrizione |
| :----------------------- | :-------------------------------- |
| Blu fisso | Avvio in corso |
| Bianco lampeggiante | Avviato, ma senza connessione Internet |
| Bianco fisso | Connesso a Internet |
| Blu e bianco lampeggianti | Aggiornamento firmware in corso |

## Pulsante { #button }

Sul pannello laterale di Comet è presente un pulsante.

| Funzione | Operazione | Stato del LED |
| :------------------------- | :--------------------------------------- | :------------------------------------ |
| Accesso alla modalità di scrittura U-Boot | Con il dispositivo acceso, tenere premuto <br>il pulsante per più di **3s**, quindi rilasciarlo | Durante la pressione: blu lampeggiante <br>Modalità U-Boot attiva: blu fisso |
| Ripristino | Con il dispositivo acceso, tenere premuto <br>il pulsante per **8–20s**, quindi rilasciarlo | Pressione di 1-8s: lampeggio lento <br>Pressione di 8-20s: lampeggio rapido |

## Contenuto della confezione { #package-contents }

- 1 x Comet (GL-RM1)
- 1 x Manuale utente
- 1 x Biglietto di ringraziamento
- 1 x Cavo Ethernet
- 1 x Cavo HD
- 1 x Cavo USB (Type-A a Type-C)
- 1 x Cavo USB (Type-C a Type-C)

!!! Warning "Avvertenza"

    Non è possibile usare alimentatori PD.
