# Guida utente di Comet PoE (GL-RM1PE) {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) è la versione Power-over-Ethernet di [Comet (GL-RM1)](../gl-rm1/index.md), progettata per semplificare l'installazione con un solo cavo. Il modello PoE riceve alimentazione e connettività di rete tramite un unico cavo Ethernet, riducendo l'ingombro dei cavi e semplificando l'installazione, soprattutto negli ambienti difficili da raggiungere.

Questa versione aumenta inoltre la capacità eMMC a 32GB, offrendo più spazio per log di sistema, registrazioni o firmware personalizzati.
