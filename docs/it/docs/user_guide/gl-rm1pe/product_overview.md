## LED {#led}

Sul pannello superiore di Comet PoE è presente un indicatore LED.

| Stato del LED | Descrizione |
| :----------------------- | :-------------------------------- |
| Blu fisso | Avvio in corso |
| Bianco lampeggiante | Avviato, ma senza connessione Internet |
| Bianco fisso | Connesso a Internet |
| Blu e bianco lampeggianti | Aggiornamento firmware in corso |

## Contenuto della confezione { #package-contents }

- 1 x Comet PoE (GL-RM1PE)
- 1 x Manuale utente
- 1 x Cavo Ethernet
- 1 x Cavo HD
- 1 x Cavo USB (Type-A a Type-C)
- 1 x Cavo USB (Type-C a Type-C)
