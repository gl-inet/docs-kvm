# Exporter les journaux de l’appareil et de l’application {#how-to-export-device-logs-and-app-logs}

Ce tutoriel explique comment exporter les journaux de votre KVM et de l’application GLKVM pour le dépannage.

## Journaux de l’appareil {#device-logs}

Connectez-vous à la console du KVM, cliquez sur **Help**, puis sélectionnez **Export Log Files**.

![Journaux de l’appareil](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/device_log.png){class="glboxshadow"}

## Journaux de l’application {#app-logs}

Vous pouvez exporter les journaux depuis l’application de bureau ou l’application mobile.

Dans l’application de bureau GLKVM, connectez-vous, cliquez sur l’icône en forme de point d’interrogation en haut à droite et sélectionnez **Export Log**.

![Journaux du client Web](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/web_app_log.png){class="glboxshadow"}

Dans l’application mobile GLKVM, connectez-vous, accédez à **Settings** -> **Help Center**, puis cliquez sur **Export Logs**.

![Journaux de l’application iOS](https://static.gl-inet.com/docs/kvm/tutorials/export_device_and_app_logs/ios_app_log.png){class="glboxshadow"}
