# Utiliser le mur d’écrans dans le cloud {#how-to-use-the-cloud-based-screen-wall-feature}

Le mur d’écrans dans le cloud est une fonction premium qui permet de consulter les écrans de plusieurs appareils sur une seule page et de suivre facilement leur état.

**Remarque :** Mettez le micrologiciel de votre KVM à jour vers la version 1.7 avant d’utiliser cette fonction.

Suivez les étapes ci-dessous pour utiliser le mur d’écrans dans le cloud.

1. Associez votre KVM au cloud. Consultez [Associer votre KVM au cloud](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud) pour en savoir plus.

    ![Connexion au cloud](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/cloud_login.png){class="glboxshadow"}

2. Une fois l’association terminée, connectez-vous à [https://glkvm.com/](https://glkvm.com/){target="_blank"}. Les appareils associés apparaissent dans la liste. Assurez-vous qu’ils sont en ligne.

    ![Liste des appareils](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/device_list.png){class="glboxshadow"}

3. Cliquez sur **Screen Wall** dans le menu de gauche, puis sur **Setup Screen Wall**.

    ![Mur d’écrans](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/setup_screen_wall.png){class="glboxshadow"}

4. Sélectionnez les KVM à afficher sur le mur d’écrans, puis cliquez sur **Save Screen Wall** en haut à droite.

    ![Sélection d’un appareil](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/select_device.png){class="glboxshadow"}

    **Remarque :** Les appareils dont le micrologiciel est antérieur à la version 1.7 sont grisés et ne peuvent pas être sélectionnés. Mettez d’abord leur micrologiciel à jour.

5. Une fois les paramètres enregistrés, la connexion aux appareils sélectionnés commence via le cloud.

    ![Connexion en cours](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/connecting.png){class="glboxshadow"}

6. Une fois la connexion établie, saisissez le mot de passe administrateur de chacun de vos KVM.

    ![Connexion administrateur](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/admin_login.png){class="glboxshadow"}

7. Vous pouvez alors consulter les écrans de plusieurs appareils sur une seule page.

    ![Affichage du mur d’écrans](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/screen_wall_display.png){class="glboxshadow"}
