# Partager des appareils KVM avec d’autres utilisateurs {#how-to-share-kvm-devices-with-others}

Le partage d’appareils via le cloud est une fonction premium qui permet d’accorder à d’autres utilisateurs un accès à distance à vos KVM et de gérer leurs autorisations à distance.

**Remarque :** Mettez le micrologiciel de votre KVM à jour vers la version 1.7 avant d’utiliser cette fonction.

Suivez les étapes ci-dessous pour partager un KVM avec d’autres utilisateurs.

1. Associez votre KVM au cloud. Consultez [Associer votre KVM au cloud](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud) pour en savoir plus.

    ![Connexion au cloud](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/cloud_login.png){class="glboxshadow"}

2. Une fois l’association terminée, connectez-vous à [https://glkvm.com/](https://glkvm.com/){target="_blank"}. Les appareils associés apparaissent dans la liste. Assurez-vous qu’ils sont en ligne.

    ![Liste des appareils](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/device_list.png){class="glboxshadow"}

3. Cliquez sur le menu à trois points de la fiche de l’appareil, puis sur **Share Device**.

    ![Partage d’un appareil 1](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_1.png){class="glboxshadow"}

4. Saisissez l’adresse e-mail ou le nom d’utilisateur de l’utilisateur inscrit avec lequel vous souhaitez partager l’appareil, puis cliquez sur **Invite**.

    ![Partage d’un appareil 2](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_2.png){class="glboxshadow"}

    ![Partage d’un appareil 3](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_3.png){class="glboxshadow"}

5. Sur la plateforme cloud du destinataire, la boîte de dialogue d’invitation au partage d’appareil s’affiche. Cliquez sur **Accept**.

    ![Acceptation du partage](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/accept_share.png){class="glboxshadow"}

    Une fois l’invitation acceptée, le destinataire peut accéder à l’appareil partagé.

    ![Accès à l’appareil](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/access_device.png){class="glboxshadow"}

6. Vous pouvez consulter l’état du partage sur la plateforme cloud.

    ![Partage établi](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_successfully.png){class="glboxshadow"}

    Pour arrêter le partage, cliquez sur **Terminate**. Une fois le partage arrêté, le destinataire n’a plus accès à l’appareil.

    ![Arrêt du partage](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/terminate.png){class="glboxshadow"}
