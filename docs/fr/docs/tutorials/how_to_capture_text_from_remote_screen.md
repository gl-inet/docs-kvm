# Extraire du texte de l’écran distant {#how-to-capture-text-from-the-remote-screen}

La fonction de reconnaissance de texte vous permet de sélectionner une zone de l’écran distant pour en extraire facilement le texte. Elle repose sur la reconnaissance optique de caractères (OCR) et a été introduite dans le micrologiciel v1.9.0.

Cette fonction permet d’extraire du texte de l’écran distant (celui de l’appareil contrôlé) et de le copier sur l’appareil de contrôle.

Suivez les étapes ci-dessous pour extraire du texte de l’écran distant.

## Micrologiciel v1.10 et versions ultérieures {#firmware-v110-and-above}

1. Connectez-vous à la console du KVM et accédez à **Toolbox** -> **OCR**. Cliquez sur la flèche vers le bas pour sélectionner la langue de reconnaissance souhaitée, par exemple chinois, anglais ou bilingue (Zh/En).

    ![Reconnaissance OCR 1](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_1.png){class="glboxshadow"}

2. Cliquez sur **Capture** : l’écran distant s’assombrit. Pour quitter la capture de texte, cliquez sur **Cancel**.

    ![Reconnaissance OCR 2](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_2.png){class="glboxshadow"}

3. Tracez un cadre autour du texte à extraire, comme illustré ci-dessous.

    ![Reconnaissance OCR 3](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_3.png){class="glboxshadow"}

4. Le système reconnaît automatiquement le texte de la zone sélectionnée. Vous pouvez ensuite le copier selon vos besoins.

    ![Reconnaissance OCR 4](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/ocr_recognition_4.png){class="glboxshadow"}

## Micrologiciel v1.9.x {#firmware-v19x}

1. Connectez-vous à la console du KVM. Cliquez sur la flèche vers le bas pour sélectionner la langue de reconnaissance souhaitée, par exemple chinois, anglais ou bilingue (Zh/En).

    ![Reconnaissance de texte 1](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/1.png){class="glboxshadow"}

2. Cliquez sur l’icône **« T »** en haut, au centre de la barre d’outils : l’écran distant s’assombrit.

    ![Reconnaissance de texte 2](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/2.png){class="glboxshadow"}

3. Tracez un cadre autour du texte à extraire, comme illustré ci-dessous.

    ![Reconnaissance de texte 3](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/3.png){class="glboxshadow"}

4. Le système reconnaît automatiquement le texte de la zone sélectionnée. Vous pouvez ensuite le copier selon vos besoins.

    ![Reconnaissance de texte 4](https://static.gl-inet.com/docs/kvm/tutorials/text_recognition/4.png){class="glboxshadow"}
