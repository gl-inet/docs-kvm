# Désactiver le service cloud {#how-to-disable-cloud-service}

Le service cloud des KVM GL.iNet est activé par défaut. Il permet d’associer les KVM à un compte cloud pour y accéder à distance.

Si vous ne souhaitez pas l’utiliser, vous pouvez le désactiver manuellement. L’accès à distance via le service cloud et l’application GLKVM devient alors indisponible. Pour le réactiver, connectez-vous au KVM localement avec son nom de domaine ou son adresse IP, ou à distance via Tailscale.

Suivez les étapes ci-dessous si vous souhaitez désactiver le service cloud.

1. Connectez-vous au KVM et accédez à **Cloud Service** en haut à droite. Cliquez sur l’icône d’engrenage, puis sur **Disable**.

    ![Désactivation du cloud](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_1.png){class="glboxshadow" width="400"}

2. Une fois le service désactivé, la page apparaît comme ci-dessous.

    ![Désactivation du cloud](https://static.gl-inet.com/docs/kvm/faq/disable_cloud/disable_cloud_2.png){class="glboxshadow"}
