# Dissocier mon KVM du cloud {#how-to-unbind-my-kvm-device-from-the-cloud}

Vous pouvez dissocier un KVM du cloud de trois façons : depuis un accès local, l’application GLKVM ou le cloud.

## Dissociation depuis un accès local {#unbind-via-local-access}

1. Vérifiez que l’ordinateur est sur le même réseau local que le KVM.

2. Ouvrez un navigateur (Chrome ou Edge recommandé). Saisissez `glkvm.local` ou l’adresse IP du KVM dans la barre d’adresse pour ouvrir la page de connexion locale GLKVM. Connectez-vous avec le mot de passe administrateur.

3. Accédez à **Cloud Service** en haut à droite, cliquez sur l’icône d’engrenage et sélectionnez **Unbind**.

    ![Suppression de l’association en local](https://static.gl-inet.com/docs/kvm/faq/unbind/local_unbind.png){class="glboxshadow"}

## Dissociation depuis GLKVM {#unbind-via-glkvm-app}

1. Connectez-vous à GLKVM et cliquez sur **Manage** en haut à droite de votre appareil.

    ![Suppression de l’association depuis l’application](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_1.png){class="glboxshadow"}

2. Cliquez sur **More**, puis sur **Unbind**.

    ![Suppression de l’association dans l’application](https://static.gl-inet.com/docs/kvm/faq/unbind/app_unbind_2.png){class="glboxshadow"}

## Dissociation depuis le cloud {#unbind-via-the-cloud}

1. Ouvrez un navigateur (Chrome ou Edge recommandé). Saisissez `glkvm.com` dans la barre d’adresse et connectez-vous à votre compte cloud.

2. Cliquez sur l’icône à trois points en bas à droite de votre appareil, puis sur **Device Detail**.

    ![Suppression de l’association depuis le cloud](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_1.png){class="glboxshadow"}

3. Sur la page des détails, cliquez sur **Unbind**.

    ![Suppression de l’association depuis le cloud](https://static.gl-inet.com/docs/kvm/faq/unbind/cloud_unbind_2.png){class="glboxshadow gl-80-desktop"}
