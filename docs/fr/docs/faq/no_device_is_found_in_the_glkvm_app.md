# Que faire si aucun appareil n’est trouvé dans GLKVM ? {#what-should-i-do-if-no-device-is-found-in-the-glkvm-app}

Lors du premier ajout d’un KVM, l’option **Auto Discover** peut afficher **No device found** dans GLKVM.

![Aucun appareil détecté](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

Essayez les vérifications suivantes :

1. Vérifiez que tous les câbles sont correctement branchés au KVM : câble d’alimentation Type-C, HDMI, Ethernet (si nécessaire) et USB-A.

2. Vérifiez que le KVM est connecté à Internet. Un voyant blanc fixe indique une connexion réseau normale.

3. Vérifiez que le KVM et l’appareil de contrôle sont connectés au même réseau.
