# Que faire si mon KVM ne s’allume pas ? {#what-should-i-do-if-my-kvm-does-not-power-on}

Si le KVM ne démarre pas alors que le câble d’alimentation est branché, procédez aux vérifications suivantes.

1. Vérifiez que le câble d’alimentation est branché sur le bon port USB Type-C.

    Le Comet (GL-RM1), par exemple, dispose de deux ports USB Type-C : l’un pour l’alimentation (relié à un adaptateur secteur), l’autre pour les signaux (relié à l’appareil contrôlé par un câble USB).

    Si les ports sont inversés, le KVM ne s’allume pas et le clavier et la souris ne répondent pas.

    Branchez le câble d’alimentation sur le port USB Type-C à côté du port Ethernet.

    ![Branchement du câble d’alimentation](https://static.gl-inet.com/docs/kvm/faq/power_cable_connected_but_device_unpowered/plug_in_power_cable.jpg){class="glboxshadow"}

2. Essayez un adaptateur secteur standard 5V 2A et vérifiez si le voyant s’allume.

    Évitez les adaptateurs utilisant le protocole PD.

    Un voyant bleu fixe indique que l’appareil démarre.

3. Maintenez le bouton Reset enfoncé pendant plus de 8 secondes pour rétablir les paramètres d’usine.
