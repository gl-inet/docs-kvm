# Quelle offre du service KVM Cloud choisir ? {#which-kvm-cloud-service-plan-is-right-for-you}

Le service KVM Cloud propose deux offres : Standard, gratuite, et Advanced, payante. Le mur d’écrans et le partage d’appareils sont des fonctions premium disponibles uniquement avec Advanced. Le tableau suivant compare les fonctions incluses. Vous pouvez passer à Advanced selon vos besoins.

## Comparaison des avantages {#benefits-comparison}
| Fonction principale | Standard | Advanced |
| ---- | ---- | ---- |
| Connexion de base | ✓ Connexion de base à vie | ✓ Connexion de base à vie |
| Appareils associés | ✓ Nombre illimité par compte | ✓ Nombre illimité par compte |
| Mur d’écrans | <span style="color:red;">✗</span> <span style="color:#888;">Non pris en charge</span> | ✓ Jusqu’à **9** ajouts |
| Partage d’appareils | <span style="color:red;">✗</span> <span style="color:#888;">Non pris en charge</span> | ✓ Partage avec jusqu’à **5** utilisateurs |
| Voies d’accès à distance | ✓ Une voie active par appareil | ✓ Plusieurs voies simultanées par appareil |
| Accès aux appareils connectés | ✓ Nombre illimité d’appareils | ✓ Nombre illimité d’appareils |

**Remarque :** Les voies d’accès à distance s’appliquent au cloud et aux applications GLKVM.
