# Mettre à jour le micrologiciel du KVM {#how-to-upgrade-your-kvms-firmware}

Les mises à jour du micrologiciel ajoutent des fonctions et améliorent la stabilité de l’appareil. Suivez les étapes ci-dessous pour effectuer la mise à jour.

1. Connectez-vous à la console du KVM et cliquez sur la version du micrologiciel en haut à droite pour rechercher les mises à jour.

    ![Mise à jour](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. Si une version plus récente est disponible, vous pouvez effectuer une **mise à jour en ligne** dans la fenêtre qui s’ouvre. Sinon, le micrologiciel est à jour.

    ![Micrologiciel à jour](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. Cliquez sur **Update Settings** pour effectuer une mise à jour locale, rejoindre le programme bêta ou conserver la configuration actuelle.

    ![Mise à jour des paramètres](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade** : téléchargez le dernier micrologiciel depuis le [centre de téléchargement](https://dl.gl-inet.com/kvm){target="_blank"} avant d’effectuer une mise à jour locale.

    - **Join Beta Program** : le micrologiciel bêta donne un accès anticipé aux futures fonctions. Il peut être instable et affecter les performances de l’appareil. Rejoignez ce programme uniquement si vous acceptez de tester un logiciel en préversion.

    - **Save current configuration** : conserve l’association à votre compte de service cloud.
