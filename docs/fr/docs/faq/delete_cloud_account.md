# Supprimer mon compte cloud {#how-to-delete-my-cloud-account}

Pour des raisons de sécurité, vous pouvez supprimer votre compte cloud si vous ne l’utilisez plus.

**AVERTISSEMENT :**

1. Les routeurs et les KVM GL.iNet partagent un service cloud commun. La suppression du compte s’applique aux routeurs comme aux KVM.
2. Elle efface définitivement tous les services, données et informations personnelles associés, sans possibilité de récupération.
3. Quittez toutes les organisations avant de procéder à la suppression.

---

Vous pouvez supprimer votre compte cloud de deux façons : via l’application GLKVM ou via le cloud.

Suivez les étapes ci-dessous si vous souhaitez supprimer votre compte.

## Suppression dans l’application GLKVM {#delete-in-glkvm-app}

1. Connectez-vous à GLKVM, cliquez sur votre profil en haut à gauche, puis sur **Settings**.

    ![Suppression du compte dans l’application 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete1.png){class="glboxshadow"}

2. Dans les paramètres **Account**, cliquez sur **Delete**. Toutes vos données seront effacées. Procédez avec prudence.

    ![Suppression du compte dans l’application 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete2.png){class="glboxshadow"}

## Suppression dans le cloud {#delete-in-the-cloud}

1. Ouvrez un navigateur Web sur votre ordinateur (Chrome ou Edge est recommandé pour une meilleure compatibilité). Saisissez `glkvm.com` dans la barre d’adresse et connectez-vous avec votre compte cloud.

2. Une fois connecté, cliquez sur votre profil en haut à droite, puis sur **Personal Center**.

    ![Suppression du compte cloud 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete1.png){class="glboxshadow"}

3. Faites défiler la page jusqu’en bas et cliquez sur **Delete**. Toutes vos données seront effacées. Procédez avec prudence.

    ![Suppression du compte cloud 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete2.png){class="glboxshadow"}
