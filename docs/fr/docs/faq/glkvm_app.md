# Application GLKVM {#glkvm-app}

![Icône de l’application GLKVM](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

GLKVM est une application pour Windows et macOS permettant d’accéder à distance aux appareils connectés à un KVM GL.iNet et de les contrôler. Elle convient aux professionnels de l’informatique, aux télétravailleurs et aux utilisateurs avancés ayant besoin d’un accès direct à des machines distantes.

Sous macOS, téléchargez-la [ici](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"}.

Sous Windows, téléchargez-la [ici](https://www.gl-inet.com/app-rm/){target="_blank"} (Windows 10 et versions ultérieures uniquement).

Sous Android, téléchargez-la [ici](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"}.

Sous iOS, téléchargez-la sur l’[App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"}.

Vous pouvez également utiliser le service cloud pour un accès à distance depuis un navigateur Web. Cliquez [ici](remote_access_via_cloud.md) pour en savoir plus.
