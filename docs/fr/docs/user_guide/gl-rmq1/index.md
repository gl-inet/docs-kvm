# Guide d’utilisation du Comet Q (GL-RMQ1) {#comet-q-gl-rmq1-user-guide}

Le Comet Q est un appareil qui tient dans la paume de la main et se raccorde en USB-C aux téléphones mobiles, ordinateurs Mac mini et ordinateurs portables compatibles (prise en charge de DP Alt Mode requise). Une fois le raccordement effectué, ouvrez un navigateur pour contrôler entièrement l’appareil cible, sans installer de logiciel supplémentaire ni effectuer de configuration complexe. Son écran tactile intégré de 1,8 pouce permet de configurer rapidement l’appareil, de consulter son état et de déclencher des actions directement depuis le boîtier.

Il s’agit du premier KVM au monde prenant en charge les iPhone : vous pouvez déverrouiller un appareil iOS, toucher l’écran, balayer et utiliser toutes ses fonctions depuis un PC Windows, une possibilité auparavant indisponible.
