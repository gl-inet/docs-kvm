## Voyant LED {#led}

Un voyant LED se trouve sur le dessus de Comet PoE.

| État du voyant LED | Description |
| :----------------------- | :-------------------------------- |
| Bleu fixe | Démarrage en cours |
| Blanc clignotant | Appareil démarré, sans accès à Internet |
| Blanc fixe | Connecté à Internet |
| Bleu et blanc clignotants | Mise à jour du micrologiciel |
