# Guide d’utilisation de Comet PoE (GL-RM1PE) {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) est la version Power-over-Ethernet du [Comet (GL-RM1)](../gl-rm1/index.md), conçue pour simplifier l’installation grâce à un seul câble. Le modèle PoE assure l’alimentation et la connexion réseau par un unique câble Ethernet, ce qui réduit l’encombrement des câbles et facilite l’installation, notamment dans les endroits difficiles d’accès.

Cette version porte également la capacité eMMC à 32GB, ce qui offre davantage d’espace pour les journaux système, les enregistrements ou les micrologiciels personnalisés.
