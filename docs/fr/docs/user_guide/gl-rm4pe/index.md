# Guide d’utilisation du Comet X (GL-RM4PE) {#comet-x-gl-rm4pe-user-guide}

Le Comet X est un KVM distant à quatre ports avec prise en charge PoE, qui peut être connecté à jusqu’à 4 serveurs dans votre baie. Une fois configuré, il vous permet de contrôler tous les appareils connectés depuis n’importe où, au moyen d’un navigateur ou de l’application, avec une vidéo fluide en 4K@30fps et sans logiciel supplémentaire. Son écran tactile intégré de 3,69 pouces affiche en un coup d’œil les adresses IP, l’état de connexion et les sessions actives. L’alimentation PoE simplifie le déploiement et réduit le nombre de câbles dans votre environnement serveur. Le stockage eMMC de 64GB sert également de dépôt intégré pour les fichiers ISO, afin de faciliter le déploiement de systèmes d’exploitation et la restauration d’urgence.
