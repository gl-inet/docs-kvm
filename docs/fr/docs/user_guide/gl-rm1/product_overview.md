## Voyant LED {#led}

Un voyant LED se trouve sur le dessus de Comet.

| État du voyant LED | Description |
| :----------------------- | :-------------------------------- |
| Bleu fixe | Démarrage en cours |
| Blanc clignotant | Appareil démarré, sans accès à Internet |
| Blanc fixe | Connecté à Internet |
| Bleu et blanc clignotants | Mise à jour du micrologiciel |

## Bouton {#button}

Un bouton se trouve sur le côté de Comet.

| Fonction | Manipulation | État du voyant LED |
| :------------------------- | :--------------------------------------- | :------------------------------------ |
| Accéder au mode de flashage U-Boot | Lorsque l’appareil est allumé, maintenez <br>le bouton enfoncé pendant plus de **3s**, puis relâchez-le | Pendant l’appui : bleu clignotant <br>Mode U-Boot activé : bleu fixe |
| Réinitialiser | Lorsque l’appareil est allumé, maintenez <br>le bouton enfoncé pendant **8–20s**, puis relâchez-le | Appui de 1-8s : clignotement lent <br>Appui de 8-20s : clignotement rapide |

## Contenu du colis {#package-contents}

- 1 x Comet (GL-RM1)
- 1 x manuel d’utilisation
- 1 x carte de remerciement
- 1 x câble Ethernet
- 1 x câble HD
- 1 x câble USB (Type-A vers Type-C)
- 1 x câble USB (Type-C vers Type-C)

!!! warning "Avertissement"

    Les adaptateurs PD ne peuvent pas être utilisés.
