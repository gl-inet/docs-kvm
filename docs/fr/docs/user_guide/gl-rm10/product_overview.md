## Écran tactile {#touchscreen}

| Affichage de l’écran | Description |
| :-------------------------------- | :------------------ |
| ![Démarrage](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/booting.png){width="650"}| **Démarrage**<br>Allumez votre Comet Pro. Le logo GL.iNet s’affiche, suivi d’une barre de progression. Lorsque celle-ci est remplie, le démarrage de l’appareil est terminé. |
| ![Mot de passe de l’écran](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/input_passcode.png)| **Définition du mot de passe de l’écran**<br>Définissez un mot de passe pour l’écran de votre Comet Pro afin de protéger votre confidentialité. |
| ![Configuration du réseau](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/setup_network.png)| **Configuration du réseau**<br>Connectez Comet Pro à un réseau Wi-Fi 2.4GHz/5GHz ou à un équipement réseau (par exemple, un routeur, un commutateur réseau ou une prise Ethernet) à l’aide d’un câble Ethernet. |
| ![Écran d’accueil](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/cables_connected.png)| **Écran d’accueil**<br>**En haut à gauche** : état du cloud et du réseau.<br>**En haut à droite** : heure système.<br>**Au centre** : adresse IP de l’appareil (affichée uniquement lorsque la connexion Internet est établie).<br>**En bas** : signal du clavier et de la souris, signal HDMI et état de la connexion USB. |
| ![Paramètres de base](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/basic_settings.png)| **Paramètres de base**<br>Depuis l’écran d’accueil, balayez du bord droit vers la gauche pour accéder aux paramètres de base : **Screen Display**, **Wi-Fi** et **Cloud Service**. |
| ![Actions système](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/system_menu.png)| **Menu système**<br>Depuis l’écran d’accueil, balayez du haut vers le bas pour accéder au menu système, qui comprend **Reboot** et **Lock Screen**. |
| ![Heure](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/time.png)| **Écran de verrouillage**<br>L’écran de verrouillage affiche l’heure et la date. |
| ![Réinitialisation](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm10/touchscreen/reset.png)| **Réinitialisation aux paramètres d’usine**<br>Lorsque le KVM est allumé, insérez une pointe dans l’orifice de réinitialisation et maintenez-la enfoncée pendant 8 secondes pour rétablir les paramètres d’usine. Relâchez-la avant 8 secondes pour annuler la réinitialisation. |

## Contenu du colis {#package-contents}

- 1 x Comet Pro (GL-RM10)
- 1 x manuel d’utilisation
- 1 x carte de remerciement
- 1 x câble Ethernet
- 2 x câbles HD
- 1 x câble USB (Type-A vers Type-C)
- 1 x câble USB (Type-C vers Type-C)
- 1 x adaptateur secteur USB-A
- 1 x adaptateur de prise (selon le pays de livraison)
