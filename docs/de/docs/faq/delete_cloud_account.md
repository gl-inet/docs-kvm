# Cloud-Konto loeschen

Aus Sicherheitsgruenden koennen Sie Ihr Cloud-Konto loeschen, wenn es nicht mehr verwendet wird. 

**WARNUNG**:

1. GL.iNet Router und KVM-Geraete verwenden einen gemeinsamen Cloud-Dienst. Wenn Sie Ihr Cloud-Konto loeschen, wirkt sich die Aenderung sowohl auf Router als auch auf KVM-Geraete aus.
2. Durch das Loeschen werden alle zugehoerigen Dienste, Daten und personenbezogenen Informationen dauerhaft entfernt. Eine Wiederherstellung ist nicht moeglich.
3. Verlassen Sie bitte alle Organisationen, bevor Sie mit dem Loeschen fortfahren.

---

Es gibt zwei Moeglichkeiten, Ihr Cloud-Konto zu loeschen: ueber die GLKVM App oder ueber die Cloud.

Fuehren Sie bei Bedarf die folgenden Schritte aus, um Ihr Cloud-Konto zu loeschen.

## In der GLKVM App loeschen

1. Melden Sie sich in der GLKVM App an, klicken Sie oben links auf Ihr Profil und dann auf **Settings**. 

    ![app delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete1.png){class="glboxshadow"}

2. Klicken Sie in den **Account**-Einstellungen auf **Delete**. Dadurch werden alle Ihre Daten geloescht. Gehen Sie vorsichtig vor.

    ![app delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/app_delete2.png){class="glboxshadow"}
    
## In der Cloud loeschen

1. Starten Sie einen Webbrowser auf Ihrem Computer; fuer bessere Kompatibilitaet werden Chrome oder Edge empfohlen. Geben Sie `glkvm.com` in die Adressleiste ein und melden Sie sich mit Ihrem Cloud-Konto an.

2. Klicken Sie nach der Anmeldung oben rechts auf Ihr Profil und dann auf **Personal Center**. 

    ![cloud delete 1](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete1.png){class="glboxshadow"}

3. Scrollen Sie zum Ende der Seite und klicken Sie auf **Delete**. Dadurch werden alle Ihre Daten geloescht. Gehen Sie vorsichtig vor.

    ![cloud delete 2](https://static.gl-inet.com/docs/kvm/faq/delete_cloud_account/cloud_delete2.png){class="glboxshadow"}
