# Was kann ich tun, wenn in der GLKVM App kein Gerät gefunden wird

Wenn Sie ein KVM-Gerät zum ersten Mal hinzufügen und **Auto Discover** auswählen, kann die GLKVM App **No device found** anzeigen.

![no device found](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

Hier sind einige Tipps zur Fehlerbehebung:

1. Stellen Sie sicher, dass alle Kabel korrekt mit Ihrem KVM-Gerät verbunden sind, einschliesslich Type-C-Kabel für die Stromversorgung, HDMI-Kabel, Ethernet-Kabel (falls erforderlich) und USB-A-Kabel.

2. Stellen Sie sicher, dass Ihr KVM mit dem Internet verbunden ist. Eine dauerhaft weiß leuchtende LED zeigt eine normale Netzwerkverbindung an.

3. Stellen Sie sicher, dass Ihr KVM und das steuernde Gerät mit demselben Netzwerk verbunden sind.
