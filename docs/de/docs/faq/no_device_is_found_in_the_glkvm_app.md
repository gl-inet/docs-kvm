# Was kann ich tun, wenn in der GLKVM App kein Geraet gefunden wird

Wenn Sie ein KVM-Geraet zum ersten Mal hinzufuegen und **Auto Discover** auswaehlen, kann die GLKVM App **No device found** anzeigen.

![no device found](https://static.gl-inet.com/docs/kvm/faq/what_to_do_if_no_device_found_in_the_glkvm_app/no_device_found.png){class="glboxshadow"}

Hier sind einige Tipps zur Fehlerbehebung:

1. Stellen Sie sicher, dass alle Kabel korrekt mit Ihrem KVM-Geraet verbunden sind, einschliesslich Type-C-Kabel fuer die Stromversorgung, HDMI-Kabel, Ethernet-Kabel (falls erforderlich) und USB-A-Kabel.

2. Stellen Sie sicher, dass Ihr KVM mit dem Internet verbunden ist. Eine dauerhaft weiss leuchtende LED zeigt eine normale Netzwerkverbindung an.

3. Stellen Sie sicher, dass Ihr KVM und das steuernde Geraet mit demselben Netzwerk verbunden sind.
