# Firmware Ihres KVM aktualisieren

Firmware-Upgrades bringen neue Funktionen und verbessern die Geraetestabilitaet. Fuehren Sie die folgenden Schritte aus, um das Upgrade abzuschliessen.

1. Melden Sie sich an der KVM-Konsole an und klicken Sie oben rechts auf die Firmware-Version, um nach Updates zu suchen.

    ![upgrade](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/upgrade.png){class="glboxshadow"}

2. Wenn im Pop-up-Fenster eine neuere Firmware verfuegbar ist, koennen Sie ein **Online-Upgrade** durchfuehren. Andernfalls ist die Firmware Ihres KVM bereits aktuell.

    ![up-to-date](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/up-to-date.png){class="glboxshadow"}

3. Klicken Sie auf **Update Settings**, um ein lokales Upgrade durchzufuehren, dem Beta-Programm beizutreten oder die aktuelle Konfiguration zu speichern.

    ![update settings](https://static.gl-inet.com/docs/kvm/faq/firmware_upgrade/update_settings.png){class="glboxshadow"}

    - **Local Upgrade**: Laden Sie vor einem lokalen Upgrade die neueste Firmware aus dem [Firmware Download Center](https://dl.gl-inet.com/kvm){target="_blank"} herunter.

    - **Join Beta Program**: Beta-Firmware gibt Ihnen fruehen Zugriff auf kommende Funktionen. Beachten Sie, dass Beta-Versionen instabil sein und die Geraeteleistung beeintraechtigen koennen. Nehmen Sie nur teil, wenn Sie Vorabsoftware testen moechten. 
    
    - **Save current configuration**: Dadurch bleibt die Bindung an Ihr Cloud-Dienstkonto erhalten.
