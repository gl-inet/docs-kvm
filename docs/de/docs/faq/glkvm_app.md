# GLKVM App

![GLKVM app icon](https://static.gl-inet.com/docs/kvm/faq/glkvm_app/icon_glinet_rm.jpg){class="glboxshadow" width="128" style="border-radius:15px"}

Die GLKVM App ist eine Windows- und macOS-Anwendung für Fernzugriff und Steuerung von Geräten, die mit GL.iNet KVM verbunden sind. Sie eignet sich für IT-Fachleute, Remote-Mitarbeiter und Power-User, die direkten Zugriff auf entfernte Computer benötigen.

macOS-Benutzer können sie [hier](https://apps.apple.com/us/app/glkvm/id6740846845?mt=12){target="_blank"} herunterladen.

Windows-Benutzer können sie [hier](https://www.gl-inet.com/app-rm/){target="_blank"} herunterladen; unterstützt wird nur Win 10 und neuer.

Android-Benutzer können sie [hier](https://play.google.com/store/apps/details?id=com.glinet.kvm){target="_blank"} herunterladen.

iOS-Benutzer können sie aus dem [App Store](https://apps.apple.com/us/app/glkvm/id6754631417){target="_blank"} herunterladen.

Alternativ können Sie den Cloud-Dienst für den Fernzugriff über einen Webbrowser verwenden. Details finden Sie [hier](remote_access_via_cloud.md).
