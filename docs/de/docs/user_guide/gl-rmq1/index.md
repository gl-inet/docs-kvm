# Comet Q (GL-RMQ1) Benutzerhandbuch {#comet-q-gl-rmq1-user-guide}

Comet Q ist ein handflächengroßes Gerät, das per USB-C mit kompatiblen Mobiltelefonen, Mac-mini-Computern und Laptops verbunden wird (DP-Alt-Mode-Unterstützung erforderlich). Nach dem Anschließen können Sie einen Browser öffnen und die vollständige Kontrolle über das Zielgerät erhalten, ohne zusätzliche Softwareinstallation oder komplexe Konfiguration. Der integrierte 1,8-Zoll-Touchscreen ermöglicht die schnelle Einrichtung, Statusprüfung und das direkte Auslösen von Aktionen am Gerät.

Es ist das weltweit erste KVM mit iPhone-Unterstützung und ermöglicht es, ein iOS-Gerät von einem Windows-PC aus zu entsperren, anzutippen, zu wischen und vollständig zu bedienen - eine bisher nicht verfügbare Funktion.
