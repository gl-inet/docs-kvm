# Comet PoE (GL-RM1PE) Benutzerhandbuch {#comet-poe-gl-rm1pe-user-guide}

Comet PoE (GL-RM1PE) ist die Power-over-Ethernet-Version des [Comet (GL-RM1)](../gl-rm1/index.md) und für einfache Ein-Kabel-Installationen konzipiert. Das PoE-Modell überträgt Stromversorgung und Netzwerkverbindung über ein einzelnes Ethernet-Kabel, reduziert Kabelaufwand und vereinfacht die Installation, insbesondere in schwer zugänglichen Umgebungen.

Zusätzlich wurde bei dieser Version die EMMC-Kapazität auf 32 GB erhöht, sodass sie Systemprotokolle, Aufzeichnungen oder benutzerdefinierte Firmware besser verarbeiten kann.
