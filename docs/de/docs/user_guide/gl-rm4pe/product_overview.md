## Schnittstellen

![interface1](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/overview/interface1.jpg){class="glboxshadow"}

![interface2](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/overview/interface2.jpg){class="glboxshadow"}

Comet X kann gleichzeitig mit vier Zielgeraeten verbunden werden, wobei jeweils nur ein Geraet gesteuert werden kann. Sie koennen vor Ort ueber die physische Taste an der Vorderseite oder aus der Ferne ueber die Remote-Konsole schnell zwischen den vier verbundenen Geraeten wechseln.

Das Geraet verfuegt auf der Rueckseite ueber vier unabhaengige Kanaele. Jeder Kanal bietet einen HDMI-Anschluss fuer die Videosignaluebertragung, einen Type-C-Anschluss fuer Tastatur- und Maussignale sowie einen USB-2.0-Anschluss fuer USB-Peripheriegeraete (z. B. Fingerbot oder ATX Board).

## Touchscreen

| Screen Display                    | Beschreibung       |
| :-------------------------------- | :----------------- |
| ![booting](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/booting.png)| **Startvorgang**<br>Schalten Sie Ihren Comet X ein. Das GL.iNet Logo wird angezeigt, gefolgt von einem Fortschrittsbalken fuer den Startvorgang. Sobald der Fortschrittsbalken vollstaendig geladen ist, ist der Geraetestart abgeschlossen.|
| ![screen password](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/passcode.png)| **Bildschirmpasswort einrichten**<br>Legen Sie ein Bildschirmpasswort fuer Ihren Comet X fest, um Ihre Privatsphaere zu schuetzen.|
| ![home](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/home.png){width="600"}| **Startbildschirm**<br>**Oben rechts**: Cloud-Status und Systemzeit.<br>**Mitte**: IP-Adresse des Geraets, nur angezeigt, wenn es mit dem Internet verbunden ist.<br>**Unten**: Vier Ports, die vier Signalquellen entsprechen. Blau zeigt eine physische Verbindung an; ein gruenes Haeckchen zeigt an, dass dieser Port verwendet wird.|
| ![active signal port](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/active_port.png){width="600"}| **Active Signal Port**<br>Tippen Sie auf dem Startbildschirm auf einen aktiven Port, um HDMI-Aufloesung sowie Tastatur- und Maussignalstatus anzuzeigen.|
| ![switch signal port](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/switch.png){width="600"}| **Switch Signal Port**<br>Tippen Sie auf dem Startbildschirm auf einen inaktiven Port, um HDMI-, Tastatur- und Maussignalstatus anzuzeigen oder zu diesem Port als Signalquelle zu wechseln.|
| ![basic settings](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/basic_settings.png)| **Basic settings**<br>Wischen Sie auf dem Startbildschirm von rechts nach links, um auf die Grundeinstellungen zuzugreifen, einschliesslich **Screen Display** und **Cloud Service**.|
| ![system actions](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/system_menu.png)| **System Menu**<br>Wischen Sie auf dem Startbildschirm von oben nach unten, um auf das Systemmenue zuzugreifen, einschliesslich **Reboot** und **Lock Screen**. |
| ![time](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/time.png)| **Lock screen**<br>Der Sperrbildschirm zeigt Uhrzeit und Datum an. |
| ![reset](https://static.gl-inet.com/docs/kvm/user_guide/gl-rm4pe/touchscreen/reset.png)| **Factory Reset**<br>Halten Sie bei eingeschaltetem KVM die Umschalttaste an der Vorderseite <u>lange gedrueckt</u>, und zwar 8 Sekunden lang, um das Geraet auf Werkseinstellungen zurueckzusetzen. Lassen Sie die Taste innerhalb von 8 Sekunden los, um den Reset abzubrechen. |
