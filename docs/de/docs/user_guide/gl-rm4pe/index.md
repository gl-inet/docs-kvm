# Comet X (GL-RM4PE) Benutzerhandbuch {#comet-x-gl-rm4pe-user-guide}

Comet X ist ein Remote-KVM mit vier Ports und PoE-Unterstützung, das bis zu 4 Server in Ihrem Rack verbindet. Nach der Einrichtung können Sie alle angeschlossenen Geräte von überall aus per Browser oder App steuern und erhalten flüssiges 4K@30FPS-Video ohne zusätzliche Software. Der integrierte 3,69-Zoll-Touchscreen zeigt IP-Adressen, Online-Status und aktive Sitzungen auf einen Blick. Die PoE-Stromversorgung vereinfacht die Bereitstellung und reduziert Kabelaufwand in Ihrer Serverumgebung. Der 64-GB-eMMC-Speicher dient außerdem als integriertes Repository für ISO-Dateien und erleichtert OS-Bereitstellung sowie Notfallwiederherstellung.
