# Comet Pro (GL-RM10) Benutzerhandbuch {#comet-pro-gl-rm10-user-guide}

Comet Pro (GL-RM10) ist eine Remote-KVM-over-Wi-Fi-Lösung. Das Gerät wird von einer Quad-Core-A53-CPU angetrieben und verfügt über 1 GB DDR3-Speicher sowie 32 GB eMMC-Speicher für eine flüssige Leistung. Über den Touchscreen können Sie die IP-Adresse des Geräts auf einen Blick prüfen und grundlegende Aufgaben wie die WLAN-Einrichtung ausführen.

Für die Konnektivität unterstützt es Dual Band Wi-Fi 6 (stabil und schnell) sowie Video-Passthrough (verlustfreie Signalübertragung), plus 4K@30FPS-Videoausgabe für hochauflösende Darstellung bei der Fernsteuerung. Ob für private oder berufliche Nutzung: Comet Pro ist eine gute Wahl für effizientes Remote-Gerätemanagement.
