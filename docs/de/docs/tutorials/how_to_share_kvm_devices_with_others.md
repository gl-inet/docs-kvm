# KVM-Geräte mit anderen teilen

Die cloudbasierte Gerätefreigabe ist eine Premiumfunktion. Damit können Sie anderen Benutzern Fernzugriff auf Ihre KVM-Geräte gewähren und deren Berechtigungen aus der Ferne verwalten.

**Hinweis:** Aktualisieren Sie die KVM-Firmware auf Version 1.7, bevor Sie diese Funktion verwenden.

Gehen Sie wie folgt vor, um ein KVM-Gerät freizugeben.

1. Binden Sie Ihr KVM-Gerät an die Cloud. Einzelheiten finden Sie unter [KVM an die Cloud binden](../faq/remote_access_via_cloud.md#kvm-an-die-cloud-binden).

    ![cloud login](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/cloud_login.png){class="glboxshadow"}

2. Melden Sie sich nach dem Binden unter [https://glkvm.com/](https://glkvm.com/){target="_blank"} an. Ihre gebundenen Geräte erscheinen in der Geräteliste. Stellen Sie sicher, dass sie online sind.

    ![device list](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/device_list.png){class="glboxshadow"}

3. Klicken Sie auf das Dreipunktmenü der Gerätekarte und wählen Sie **Share Device**.

    ![share device 1](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_1.png){class="glboxshadow"}

4. Geben Sie die E-Mail-Adresse oder den Benutzernamen des registrierten Benutzers ein, mit dem Sie das Gerät teilen möchten, und klicken Sie auf **Invite**.

    ![share device 2](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_2.png){class="glboxshadow"}

    ![share device 3](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_devices_3.png){class="glboxshadow"}

5. Auf der Cloud-Plattform des Empfängers erscheint ein Dialog mit der Einladung zur Gerätefreigabe. Der Empfänger klickt auf **Accept**.

    ![accept share](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/accept_share.png){class="glboxshadow"}

    Nach Annahme der Einladung kann der Empfänger auf das freigegebene Gerät zugreifen.

    ![access device](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/access_device.png){class="glboxshadow"}

6. Den Freigabestatus sehen Sie auf der Cloud-Plattform.

    ![share successfully](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/share_successfully.png){class="glboxshadow"}

    Um die Freigabe zu beenden, klicken Sie auf **Terminate**. Danach hat der Empfänger keinen Zugriff mehr auf das Gerät.

    ![terminate](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_share_devices/terminate.png){class="glboxshadow"}
