# Statische IP fuer KVM festlegen

Dieses Tutorial beschreibt die Schritte, mit denen Sie direkt in der Konsole eine statische IP fuer Ihr GL.iNet KVM festlegen, wenn der vorgelagerte Router keine IP-Adresse zuweisen kann.

Waehlen Sie die zu Ihrer Firmware-Version passenden Schritte aus.

## Firmware v1.9 und aelter

Die folgenden Schritte verwenden Comet (GL-RM1) als Beispiel.

1. Melden Sie sich an der Comet-Konsole an und navigieren Sie zu **Settings** -> **Network**. Klicken Sie auf die IP-Adresse oder das Pfeilsymbol nach rechts.

    ![settings-network](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/settings-network.png){class="glboxshadow"}

2. Wechseln Sie zu **Static**. Geben Sie eine IP-Adresse aus dem Subnetzbereich sowie Netzmaske, Gateway und DNS-Server fuer Ihren Comet ein und klicken Sie anschliessend auf **Confirm**.

    ![ethernet-settings-static](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet-settings-static.png){class="glboxshadow"}

## Firmware v1.10 und neuer

Die folgenden Schritte verwenden Comet Pro (GL-RM10) als Beispiel.

1. Melden Sie sich an der Comet-Pro-Konsole an und klicken Sie in der Navigationsleiste auf das Symbol Settings, um die Seite Settings zu oeffnen.

    ![setting network](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/setting_network.png){class="glboxshadow"}

2. Navigieren Sie zu **Network** und klicken Sie unter Ethernet Settings auf **Static**. Geben Sie eine IP-Adresse aus dem Subnetzbereich sowie Netzmaske, Gateway und DNS-Server fuer Ihren Comet Pro ein und klicken Sie anschliessend auf **Confirm**.

    ![ethernet settings static](https://static.gl-inet.com/docs/kvm/tutorials/set_static_ip/ethernet_settings_static.png){class="glboxshadow"}
