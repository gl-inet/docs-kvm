# Cloudbasierte Screen-Wall-Funktion verwenden {#how-to-use-the-cloud-based-screen-wall-feature}

Die cloudbasierte Screen Wall ist eine Premiumfunktion. Damit können Sie die Bildschirme mehrerer Geräte auf einer einzigen Seite anzeigen und deren Status einfach überwachen.

**Hinweis:** Aktualisieren Sie Ihre KVM-Firmware auf Version 1.7, bevor Sie diese Funktion verwenden.

Gehen Sie wie folgt vor, um die cloudbasierte Screen Wall zu verwenden.

1. Binden Sie Ihr KVM-Gerät an die Cloud. Einzelheiten finden Sie unter [KVM an die Cloud binden](../faq/remote_access_via_cloud.md#bind-your-kvm-to-the-cloud).

    ![cloud login](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/cloud_login.png){class="glboxshadow"}

2. Melden Sie sich nach dem Binden unter [https://glkvm.com/](https://glkvm.com/){target="_blank"} an. Ihre gebundenen Geräte erscheinen in der Geräteliste. Stellen Sie sicher, dass sie online sind.

    ![device list](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/device_list.png){class="glboxshadow"}

3. Klicken Sie im linken Seitenmenü auf **Screen Wall** und dann auf **Setup Screen Wall**.

    ![screen wall](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/setup_screen_wall.png){class="glboxshadow"}

4. Wählen Sie die KVM-Geräte aus, die Sie in der Screen Wall anzeigen möchten, und klicken Sie oben rechts auf **Save Screen Wall**.

    ![select device](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/select_device.png){class="glboxshadow"}

    **Hinweis:** Wenn auf Ihrem Gerät eine Firmware-Version niedriger als 1.7 läuft, wird es ausgegraut und kann nicht ausgewählt werden. Aktualisieren Sie zuerst die Firmware.

5. Nach dem Speichern der Einstellungen wird die Verbindung zum ausgewählten Gerät über die Cloud gestartet.

    ![connecting](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/connecting.png){class="glboxshadow"}

6. Geben Sie nach dem Verbindungsaufbau das Admin-Passwort für jedes Ihrer KVM-Geräte ein.

    ![admin login](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/admin_login.png){class="glboxshadow"}

7. Anschließend können Sie die Bildschirme mehrerer Geräte auf einer einzigen Seite anzeigen.

    ![screen wall display](https://static.gl-inet.com/docs/kvm/tutorials/how_to_use_screen_wall/screen_wall_display.png){class="glboxshadow"}
